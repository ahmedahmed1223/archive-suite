# التصاميم المُصيَّرة

يحفظ هذا المجلد مخرجات Stitch المُصيَّرة (HTML/PNG) لكل طلب في
[`../requests`](../requests). يُسمّى الملف بمعرّف الطلب: `<id>.html` أو `<id>.png`.

عند إضافة تصيير، سجّل مساره في مصفوفة `renders` داخل ملف الطلب المقابل حتى
تبقى العلاقة بين الطلب ومخرجه صريحة.

**الحالة:** لا توجد تصييرات محفوظة بعد. تُقارَن الواجهتان المذكورتان في
[`../SYSTEM_COVERAGE.md`](../SYSTEM_COVERAGE.md) بمبادئ [`../DESIGN.md`](../DESIGN.md)
بدل مقارنة بكسل مقابل بكسل، لغياب مرجع بصري مُصيَّر لهما.
