# مسار

[English](README.md) · [فهرس التوثيق](docs/README.ar.md)

**مسار** نظام لإدارة المواد الأرشيفية والوسائط. يجمع السجل والبيانات الوصفية
والملفات والبحث والمراجعة في مساحة عمل واحدة، مع صلاحيات وسجل تدقيق يساعدان
الفِرق على إدارة المادة من الاستلام حتى استخدامها.

## نظرة عامة على النظام

- سجل موحد للمواد والبيانات الوصفية والتصنيفات والوسوم وحالة المراجعة.
- إدارة مستقلة للملفات والرفع والتنظيم قبل ضم المادة إلى الأرشيف.
- بحث متقدم بالمرشحات، ومجموعات وتعليقات ومهام ومشروعات لتنسيق العمل.
- مساعدة يراجعها الإنسان للتفريغ والملخصات واقتراح الوسوم واستخراج الكيانات.
- صلاحيات حسب الدور وسجل تدقيق وتقارير تشغيل وإعدادات تخزين قابلة للتوسعة.

## البنية المعتمدة

المسار المعتمد للمنتج هو **Next.js + Laravel**:

- `archive-next/` واجهة المستخدم المعتمدة.
- `archive-laravel/` واجهة API والتخزين والصلاحيات وسجل التدقيق.
- `docs/api/archive-contract.openapi.json` عقد OpenAPI المشترك.

## ابدأ محليًا

### المتطلبات

- `Node.js 26.5.0`
- `pnpm 11.9.0`
- Docker Desktop مع Docker Compose

يعمل `PHP 8.5.8` وComposer داخل Docker، لذلك لا تحتاج إلى تثبيتهما على جهاز
التطوير. القيم المعتمدة موجودة في `infra/platform/toolchain.v1.json`.

```powershell
pnpm install --frozen-lockfile
pnpm dev
```

يشغّل `pnpm dev` خدمة Laravel داخل Docker وواجهة Next.js محليًا. لتشغيل أحدهما
فقط استخدم `pnpm dev:next` أو `pnpm dev:laravel`.

## التحقق قبل الدمج

```powershell
pnpm verify
pnpm verify:laravel-next:live
```

يجمع `pnpm verify` فحوص العقد والأنواع والاختبارات والبناء ونظافة المستودع.
أما الأمر الثاني فيتحقق من رحلة فعلية بين Laravel وNext.js.

## النشر والإعداد

استخدم Control Center للنشر عبر Docker:

```powershell
pnpm setup
pnpm deploy
```

يدعم المنتج كذلك التشغيل المباشر دون حاويات (Native) على Windows وLinux من
خلال حزم المنصة. راجع [دليل Native](docs/native-installation.ar.md) للبناء
والنقل وإدارة الخدمات والتحقق.

تشمل خيارات التخزين المدعومة القرص المحلي و`Dropbox` و`S3` و`Azure Blob`
و`Google Drive` و`FTP/FTPS` و`SMB/CIFS` و`SFTP/SSH` و`WebDAV`.

## المساهمة

- استخدم `pnpm` من جذر المستودع.
- حدّث عقد OpenAPI والواجهة والخادم معًا عند تغيير واجهة عامة.
- شغّل `pnpm verify` قبل فتح طلب دمج.
- ضع عمل المنتج الجديد في `archive-next/` و`archive-laravel/`.

راجع [دليل المساهمة](CLAUDE.ar.md) لتفاصيل البنية والاختبارات والتكامل المستمر.
