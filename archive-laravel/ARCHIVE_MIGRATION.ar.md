# مرجع API في Laravel

[English](ARCHIVE_MIGRATION.md) · [فهرس التوثيق](../docs/README.ar.md)

Laravel هو مالك سلوك API والتخزين والصلاحيات. يحتوي عقد OpenAPI المشترك على
المسارات والطلبات والاستجابات الحالية، لذلك يستخدم هذا المستند كمرجع للتطوير
والتحقق لا كقائمة بديلة للمسارات.

شغّل `pnpm verify:laravel` لاختبارات الخدمة و`pnpm verify:laravel-next:live`
لرحلة التكامل. تستخدم الترحيلات الآمنة نسخة احتياطية قبل تغيير البنية عند
الحاجة.
