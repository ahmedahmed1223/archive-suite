# عقد API في Archive Suite

[English](README.md) · [فهرس التوثيق](../README.ar.md)

يحتوي هذا المجلد على عقد API المستقل عن إطار العمل للمسار المعتمد المبني على
Laravel وNext.js. تملك Laravel السلوك والتخزين، وتستهلك Next.js العقد ذي
الإصدار المحدد.

## الملفات

- `archive-contract.openapi.json`: عقد OpenAPI 3.1 للمصادقة والسجلات والبحث
  والملفات والمجلدات والحقوق وروابط المشاركة العامة.

## قواعد العقد

- غيّر العقد وتنفيذ Laravel وعميل Next.js في الالتزام نفسه.
- ولّد عميل Next.js من العقد أو اكتبه وفقًا له، ولا تفترض مسارات غير موثقة.
- حافظ على غلاف النجاح `{ "ok": true, ... }` وغلاف الخطأ
  `{ "ok": false, "error": "..." }`.
- استخدم ملف تعريف ارتباط `HttpOnly` لحالة التجديد أو الجلسة في المتصفح؛ لا
  تحفظ رموز الوصول في `localStorage`.
- نفّذ مسارات المنتج العامة في Laravel فقط.

## مجموعات المسارات

يشمل العقد المصادقة والسجلات والبحث والملفات والحقوق والمشاركة. تحقق من الملف
نفسه للحصول على الطلبات والاستجابات الحالية.

## ما الجديد

يغطي العقد الآن أيضًا: إعدادات تجربة المستخدم وإدارة القدرات؛ جلسات مراجعة
الوسائط وتعليقات الخط الزمني وإصدارات النص المفرّغ والمشتقات المخزَّنة وروابط
المراجعة الخارجية المثبَّتة بالإصدار؛ قوالب مهام المشروع وسياسة التصعيد؛
سياسة العمليات الحساسة وطلبات الموافقة المزدوجة؛ وقوالب المفردات. يبقى
`archive-contract.openapi.json` المرجع الوحيد لشكل الطلبات والاستجابات — اقرأه
مباشرة بدل الاعتماد على هذا الملخص لتفاصيل الحقول.

```bash
pnpm verify:api-contracts
pnpm verify:api-generated
```
