# Masar Arabic interface glossary

[العربية](arabic-ui-glossary.md) · [Documentation](README.md)

This glossary preserves the Arabic product vocabulary used in Masar. Use
`سجل` for an archive record, `مادة` for a media item, `بيانات وصفية` for
metadata, `صلاحيات` for permissions, `نسخة احتياطية` for backup, and
`استعادة` for restore. Keep technical identifiers, paths, and commands in
their exact original form.
