# AI-806 — تقييم الذكاء متعدد الوسائط لإصدار 1.2

[English](ai-multimodal-evaluation-v1.2.md)

## القرار

لا يُفعّل إنشاء الصور أو النسخ الصوتي أو إعادة الترتيب عبر مزود خارجي في الإصدار 1.2. تبقى مسارات Whisper وOCR الحالية هي مسارات الإنتاج المعتمدة.

## شروط إعادة الفتح

يلزم قياس دقة عربية، وسقف تكلفة، وموافقة مالك البيانات، وخطة استرجاع تحافظ على المسارات الحالية. تظل النتائج اقتراحات تحتاج مراجعة بشرية.
