    - paragraph: راجع مسار التهيئة السريع أو المتقدم قبل بدء العمل اليومي.

  - button "تحديث الحالة"
  - text: مفعلة للمشرف التدقيق مفروض
  - region "حالة التحكم بالنظام":
    - article:
      - strong: مفعلة للمشرف
      - paragraph: الصلاحية متاحة، لكن كل إجراء لا يزال يتحقق من الخادم.
    - article:
      - strong: نطاق حساس
      - paragraph: لا توجد محاكاة في الواجهة؛ التنفيذ الحقيقي يمر عبر الخادم فقط.
  - region "إجراءات التحكم":
    - heading "الإجراءات المتاحة" [level=2]
    - paragraph: كل إجراء يتحقق من التفعيل والصلاحية على الخادم قبل التنفيذ، بصرف النظر عن حالة هذه الواجهة.
    - article:
      - strong: تفريغ ذاكرة التخزين المؤقت
      - paragraph: يفرّغ ذاكرة التخزين المؤقت وإعدادات الخادم المخبأة.
      - text: يسجل محاولة system_control.allowed أو blocked
      - button "تنفيذ"
    - article:
      - strong: تشغيل نسخة احتياطية فورية
      - paragraph: يُنشئ نسخة احتياطية جديدة فورًا (مطابق لزر النسخ الاحتياطي).
      - text: يرتبط بسجل النسخ الاحتياطي والتدقيق
      - button "تنفيذ"
