# V1-X03 — تفريغ عربي على GPU: تشغيل حي، لا يُغلق

## النتيجة — 2026-08-04

نُفِّذ أول تفريغ عربي حقيقي على GPU فعلي (لا محاكاة): نموذج `large-v3` عبر
`whisper-ctranslate2` على `NVIDIA GeForce RTX 4060`، بجهاز `cuda` ونوع حساب
`int8`، على عيّنات صوتية عربية حقيقية مع نصوص مرجعية دقيقة.

**البند يبقى مفتوحًا** — السبب في «ما يمنع الإغلاق» أدناه، وأهمّه أن التشغيل
لم يمرّ عبر مسار المنتج.

## العيّنة الصوتية ورخصتها

| الحقل | القيمة |
| --- | --- |
| المجموعة | `google/fleurs`، الإعداد `ar_eg`، الشطر `test` |
| الرخصة | **CC-BY-4.0** |
| المصدر | https://huggingface.co/datasets/google/fleurs |
| عدد العيّنات | **3** (69 كلمة مرجعية إجمالًا) |

**بديل موثَّق:** طُلب استخدام Mozilla Common Voice (CC0)، لكنه غير متاح دون
مصادقة — أعادت واجهة `datasets-server` رمز 404 لكل من
`mozilla-foundation/common_voice_17_0` و`common_voice`. اختير FLEURS لأنه
مفتوح الرخصة، متاح دون حساب، **ويرفق نصًا مرجعيًا دقيقًا لكل مقطع** وهو شرط
قياس WER. الصوت والمخرجات في `artifacts/v1-x03/` خارج إدارة المصدر.

## الدقة

| الملف | WER بعد التطبيع | WER الخام |
| --- | --- | --- |
| `fleurs-ar-eg-0` | 13.3% (2/15) | 13.3% |
| `fleurs-ar-eg-1` | 23.3% (7/30) | 22.2% |
| `fleurs-ar-eg-2` | 4.2% (1/24) | 20.8% |
| **الإجمالي** | **14.49%** (10 أخطاء / 69 كلمة) | **19.70%** |

التطبيع يزيل التشكيل والتطويل ويوحّد صور الألف والياء والتاء المربوطة
وعلامات الترقيم. الفارق بين العمودين في الملف الثالث (4.2% مقابل 20.8%) يوضّح
أن معظم «الأخطاء» الخام اختلافات إملائية لا أخطاء سمعية.

> **تحذير إحصائي صريح:** 3 ملفات و69 كلمة عيّنة **صغيرة جدًا** ولا تصلح رقمًا
> مرجعيًا للدقة. الرقم مؤشِّر على أن المسار يعمل، لا قياس معتمَد.

## الكمون وموارد التشغيل

| المقياس | القيمة |

| إجمالي الصوت | ~34.8 ثانية |

الكمون أعلاه بعد تخزين النموذج مؤقتًا. التشغيل الأول شمل تنزيل `large-v3`
واستغرق 155 ثانية إجمالًا.

## فجوة مكتشفة: لا توجد صورة للمسار المُعَد

`media.whisper_binary` الافتراضي `whisper-ctranslate2` و`whisper_model`
الافتراضي `large-v3`، بينما `infra/Dockerfile.whisper` الموجودة **لا توفّر
أيًّا منهما**: تُثبّت حزمة `openai-whisper` وتُحمّل نموذج `base` فقط، على أساس
Python بلا CUDA، وتعمل كخدمة Flask. أي أن المسار المُعَد في `config/media.php`
لم تكن له صورة قابلة للتشغيل إطلاقًا. أُنشئت
`infra/Dockerfile.whisper-gpu-acceptance` **لأغراض الاختبار فقط** ولا تُعدِّل
أي صورة مشحونة.

## إعادة الإنتاج

```bash
docker build -t archive-whisper-gpu-test -f infra/Dockerfile.whisper-gpu-acceptance infra
docker run --rm --gpus all -v "$PWD/artifacts/v1-x03:/work" -v archive-whisper-models:/models \
  archive-whisper-gpu-test whisper-ctranslate2 --model large-v3 --language ar \
  --device cuda --compute_type int8 --output_dir /work/out --output_format vtt /work/audio/*.wav
```

يبقى `archive-whisper-models` مخزنًا مؤقتًا مسمّى (~عدة غيغابايت) لتفادي
إعادة التنزيل؛ يُحذف عند الحاجة بـ`docker volume rm archive-whisper-models`.

## ما يمنع الإغلاق

1. **لم يُختبر مسار المنتج.** جرى استدعاء `whisper-ctranslate2` مباشرةً، لا
   عبر `WhisperTranscriber` وLaravel كما في X01/X02/X04. فالمُثبَت هو قدرة
   النموذج والعتاد، **لا تكامل المنتج** (بناء الأوامر، تمرير الخيارات، تحليل
   المخرجات، معالجة الأخطاء). يتطلب ذلك صورة تجمع PHP وCUDA وwhisper.
2. **العيّنة ليست «معتمدة».** المعيار يشترط عيّنة عربية معتمدة؛ FLEURS مجموعة
   عامة لا عيّنة بث معتمدة من المالك، و3 ملفات لا تكفي لرقم دقة ذي دلالة.
3. **لا تغطية لنطاق البث الفعلي.** لا لهجات متعددة ولا ضجيج خلفية ولا تداخل
   متحدثين ولا مواد أرشيفية طويلة — وهي الظروف الحقيقية لأرشيف قناة.
4. **الصورة المشحونة لا تدعم GPU** كما في الفجوة أعلاه.
