# Archive Suite features and everyday work

[العربية](features-guide.ar.md) · [Documentation](README.md)

Archive Suite is an Arabic-first archive and media workspace. Its supported product
path is the Next.js application with the Laravel API.

## A practical starting point

1. Sign in with the role assigned to you.
2. Search the archive before creating a duplicate record.
3. Use **Uploads** to add files and describe them, then use **Archive** to
   refine metadata, rights, and relationships.
4. Open **Help** for role-specific guidance.

## Core work

- Create and maintain records, attachments, metadata, tags, classifications,
  and relationships.
- Search with text and filters; save useful searches and group work in
  collections.
- Check rights before downloading or sharing. Share links are permissioned and
  should be revoked when no longer needed.
- Coordinate through notes, comments, projects, and tasks while preserving the
  audit trail.

Operators configure integrations and external services through the system
settings that apply to their organisation. Use the capabilities available to
your role and contact an administrator when a required service is absent.
