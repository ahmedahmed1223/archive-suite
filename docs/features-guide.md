# دليل الميزات والاستخدام — Archive Suite

[English](features-guide.en.md) · [فهرس التوثيق](README.ar.md)

Archive Suite (مسار) منصة عربية أولًا لإدارة المواد الأرشيفية والوسائط. المسار
القانوني للتطبيق هو واجهة Next.js وخدمة Laravel API؛ كل المزايا أدناه تعمل ضمن
هذا المسار ولا تعتمد على الحزم القديمة.

## ابدأ من هنا

1. شغّل الحزمة محليًا عبر `pnpm dev`، أو ثبّت artifact موثّقًا عبر Control Center.
2. افتح `/login` وسجّل الدخول بدورك المخصص.
3. استخدم `/archive` للبحث، و`/uploads` لرفع المادة، و`/help` للدليل المدمج
   بحسب الدور.

## ما يغطيه النظام

- **السجلات والملفات:** أضف المادة، ثم أكمل بياناتها الوصفية وأرفق ملفاتها أو
  نظّم الملفات قبل أرشفتها.
- **الاكتشاف:** ابحث بالكلمات أو عوامل التصفية، واحفظ البحث أو أضفه إلى مجموعة
  عند الحاجة إلى الرجوع إليه.
- **الحقوق والمشاركة:** راجع القيود قبل التنزيل أو المشاركة، وأنشئ رابط مشاركة
  محدودًا عند توفر الصلاحية.
- **العمل الجماعي:** استخدم التعليقات والملاحظات والمهام والمشاريع لمتابعة
  المادة؛ لا تمنح المشاركة صلاحية تتجاوز الدور المخصص للمستخدم.

يضبط المشرف ميزات التكامل والخدمات الخارجية من إعدادات النظام وفق سياسة
المؤسسة. استخدم ما يظهر لك في الواجهة وصلاحيات دورك، واطلب من المشرف تهيئة
أي خدمة تحتاجها.
4. راجع `/status` عند التحقق من صحة الخدمات، واطلب من المدير استخدام
   `/settings` وواجهات الحوكمة فقط عند الحاجة.

## إدارة الأرشيف

| المجال | ما يوفره النظام |
| --- | --- |
| السجل الموحد | مادة أرشيفية بملف وبيانات وصفية ونوع ووسوم وتصنيف وحالة اكتمال ونسخ تاريخية |
| التصنيف والقوالب | فئات هرمية وحقول مخصصة وقواعد ظهور وإلزام وقوالب وصف قابلة للإدارة |
| قاموس المصطلحات | أشخاص وأماكن وأحداث ومرادفات وعلاقات مرتبطة بالمواد |
| دورة الحياة | إدخال، مراجعة، اعتماد، snapshots، مفضلة، وسلة استرجاع ضمن الصلاحيات |
| الحقوق والحساسية | حالة الحقوق، حماية الحقول الحساسة، وسجل تدقيق قابل للمراجعة |

## البحث والاستكشاف

- بحث نصي مع الفلاتر حسب النوع والتصنيف والوسم والتاريخ وحالة التوصيف.
- مجموعات وعمليات بحث محفوظة مع صلاحيات صريحة للمالك والمحرر والمشاهد.
- خريطة وخط زمني وشبكة علاقات لاستكشاف الموقع والحدث والفترة والكيانات.
- تقارير تشغيلية وتصدير مقيد الصلاحيات عند السماح به.

## الوسائط والرفع والترجمة

- رفع قابل للاستئناف على أجزاء، مع جلسات رفع وحالة واستكمال وإلغاء آمن.
- ملفات فيديو وصوت وصور ووثائق وخرائط، مع معاينة وملحقات وتحويلات وسجل معالجة.
- أدوات SRT/VTT/TTML للتفريغ والتحرير والنسخ والتصدير وتخصيص العرض في الواجهة.
- مقاطع start/end وRough Cut وخرائط JSON منظمة لعمليات المونتاج.
- الرفع المجدول يمر عبر queue وscheduler مع مؤشرات صحة منفصلة.

## التعاون والإنتاج

- تعليقات، إسناد مهام، مشاريع ومجموعات، ولوحة كانبان بحالات ومسؤول وتاريخ تحديث.
- روابط مشاركة محددة المدة والصلاحية مع إبطال خادمي.
- تسليم مادة بين الأقسام، صندوق وارد مركزي، ودفتر تدقيق للانتقالات.
- النسخ الاحتياطي والاستعادة مع manifest وchecksum وrollback ذري.

## الإدارة والأمان

- أدوار وصلاحيات وsessions آمنة وقيود على الحقول الحساسة.
- سجل تدقيق للعمليات الإدارية والمحتوى، مع تنقيح الأسرار في السجلات وحزم الدعم.
- Control Center للتثبيت والتحديث والصحة وعمليات الدعم؛ لا تطلب مسارات التشغيل
  العادية أوامر Docker يدوية من المشغل.
- سجل مفاتيح API وإعدادات التكاملات تحت صلاحيات المدير فقط.

## الذكاء الاصطناعي والتكاملات

توفر الواجهة والخدمة نقاط ربط للتفريغ والتلخيص واقتراح الوسوم واستخراج الكيانات
والتدقيق. تظل المراجعة البشرية إلزامية قبل الاعتماد. يدعم النظام موصلات للتخزين
المحلي وS3 وDropbox وAzure Blob وGoogle Drive وFTP/FTPS وSMB/CIFS وSFTP وWebDAV.

التكامل الحي لا يصبح متاحًا تلقائيًا: يحتاج مدير النظام إلى اعتماد مزود مناسب
ومفاتيح محفوظة في secret manager واختبار اتصال منقح. لا تضع أي مفتاح أو سلسلة
اتصال في تذكرة دعم أو ملف داخل المستودع.

## الحصول على المساعدة

عند فتح بلاغ، أرفق رقم الإصدار أو digest، نوع التثبيت، الوقت والمنطقة الزمنية،
الخطوات، الدور، والأثر. لا ترسل كلمات مرور أو tokens أو مواد أرشيف أصلية. راجع
[دليل الدعم](ops/rc-launch-and-support.md) لمعايير P0/P1/P2 وحزمة الدعم المنقحة.
