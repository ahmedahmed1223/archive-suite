# المراقبة المحلية وتشخيص الدعم

[English](local-observability.md) · [فهرس التوثيق](README.ar.md)

تستخدم حزمة Docker برنامج تشغيل السجلات المحلي في Docker لكل خدمة. يدور كل
سجل عند 10 ميغابايت، ويحتفظ بخمسة ملفات. تكتب Caddy وNext.js وLaravel وخدمات
العمل الفوري السجلات بصيغة JSON. ينتقل `X-Request-ID` عبر طبقات الطلب؛ وإذا
كانت قيمته غائبة أو غير صحيحة، يستبدلها النظام بمعرّف UUID ويعيده للعميل.

شغّل `setup observability` على Windows أو `./setup.sh observability` على Linux
لعرض التنبيهات المحلية بصيغة JSON. يفحص الأمر توقف الخدمات وعمق طابور Redis
وضغط مساحة القرص وعمر النسخ الاحتياطية وتكرار أخطاء السجل، ويجمع ذلك مع فحص
قاعدة البيانات وRedis والتخزين والعامل وخدمة Reverb. لا يرسل الأمر بيانات
قياس إلى أي جهة خارجية.

القيم الافتراضية هي 100 لعمق الطابور و85% لمساحة القرص و24 ساعة لعمر النسخة
الاحتياطية وخمسة أحداث خطأ خلال 60 دقيقة. اضبط مفاتيح `OBS_*` في `infra/.env`
عند الحاجة.

ينشئ `setup support-bundle` أو `./setup.sh support-bundle` حزمة JSON محلية في
`support-bundles/`. تقتصر السجلات على 200 سطر، ويقتصر حجم الحزمة على 1
ميغابايت. تتضمن الحزمة الإصدارات وملخص إعداد منقحًا وحالة الصحة والسجلات
الحديثة وبيان Compose؛ ولا تجمع مواد الأرشيف أو الملفات المرفوعة.

راجع الحزمة قبل مشاركتها واحذفها بعد إغلاق البلاغ. يفرض الأمر صلاحية `0600`
على أنظمة POSIX، ويزيل أذونات Windows العامة. إذا تعذر تأمين الملف، يفشل إنشاء
الحزمة ويحذف الناتج.
