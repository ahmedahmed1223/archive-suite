# سياسة دعم التشغيل المباشر دون حاويات (Native)

[English](native-support.md) · [فهرس التوثيق](README.ar.md)

يدعم Archive Suite رسمياً التشغيل المباشر على Windows وLinux. تشغّل حزم Native
خدمات Laravel وNext.js المعتمدة من دون الحاجة إلى Docker على جهاز التشغيل.

## خدمات البيانات المضمنة

- يمكن توفير PostgreSQL محلياً مع `pgvector` وpgAdmin، أو الاتصال بخادم
  PostgreSQL خارجي تديره الجهة المشغّلة.
- Redis اختياري. يعمل إعداد الصف وقاعدة التخزين الافتراضيان من دون خدمة Redis؛
  ويمكن اختيار خدمة Redis متوافقة يديرها المشغّل عند الحاجة.
- ينشئ برنامج الإعداد بيانات اعتماد محمية للتطبيق وقاعدة البيانات. لا تنشر
  ملفات الإعداد أو الأسرار الناتجة.

## نطاق التشغيل

يتطلب Native على Windows إصدار Windows 10 أو 11 وموافقة مسؤول النظام عند تسجيل
الخدمات. ويتطلب Native على Linux وجود `systemd` والصلاحيات النظامية المناسبة.
تتلقى هذه المسارات معالجة للبلاغات وإصلاحات تصحيحية طوال فترة الدعم المعتادة.

راجع [دليل التثبيت](native-installation.ar.md) لبناء الحزمة وتشغيلها، و[دليل
الدعم](ops/support.ar.md) للتعامل مع البلاغات.
