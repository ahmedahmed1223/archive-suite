# التشغيل والدعم

[English](support.md) · [فهرس التوثيق](../README.ar.md)

استخدم هذا الدليل لجمع معلومات تشخيص آمنة وتقدير أثر المشكلة واستعادة Archive
Suite دون كشف مواد الأرشيف أو بيانات الاعتماد.

## قبل التشخيص

1. سجّل إصدار التطبيق ونمط التشغيل (`docker` أو `native`) ونظام الجهاز والوقت مع منطقته الزمنية.
2. شغّل `node scripts/control-center.mjs health`، ثم راجع `status` و`logs`.
3. تحقق من وجود نسخة احتياطية حديثة قبل إعادة التشغيل أو التحديث أو الاستعادة.
4. أعد إنتاج المشكلة ببيانات اصطناعية متى أمكن.

## محتوى طلب الدعم

- وصف مختصر للأثر والصفحة أو العملية المتأثرة.
- خطوات إعادة المشكلة والنتيجة المتوقعة والنتيجة الفعلية.
- دور المستخدم المعني، من دون أسماء أو بيانات شخصية.
- مقتطف منقح من السجل أو حزمة دعم منزوعة الأسرار.

لا ترفق ملف `.env` أو نسخة من قاعدة البيانات أو رموز وصول أو سلاسل اتصال أو
مفاتيح سرية أو وثائق أرشيف حقيقية بطلب منشور للعامة.

## درجة الخطورة

| الدرجة | مثال | الإجراء الأول |
| --- | --- | --- |
| حرجة | كشف بيانات أو فقدها أو توقف الخدمة بالكامل | احتواء الوصول وإيقاف الكتابة غير الآمنة وحفظ الأدلة |
| عالية | تعطل عملية أساسية دون بديل آمن | جمع معلومات التشخيص وتعيين مسؤول للمتابعة |
| عادية | خلل محدود له بديل آمن | تسجيل خطوات الإعادة وتخطيط التصحيح |

## الاستعادة الآمنة

أنشئ نسخة احتياطية وتحقق منها قبل أي استعادة. تستبدل الاستعادة البيانات الحالية
وتتطلب تأكيدًا صريحًا. بعد الاستعادة، شغّل فحص الصحة وتحقق من تسجيل الدخول
والبحث وقراءة سجل واحد وجدول النسخ الاحتياطي.

استخدم [Control Center](../control-center.ar.md) لأوامر الصيانة المدعومة، وراجع
[دليل النشر](../../DEPLOYMENT.ar.md) لإعداد العنوان العام.
