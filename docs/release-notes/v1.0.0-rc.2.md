# مسار v1.0.0-rc.2

مرشح إصدار يركّز على وضوح سير العمل اليومي، ثبات الجلسات، وضمان أن تبقى الواجهة
العربية قابلة للاستخدام على الحاسوب والجهاز اللوحي والهاتف.

## أبرز ما تغير منذ `v1.0.0-rc.1`

- **واجهة Focus Command:** نقطة أوامر موحّدة للبحث وفتح الصفحات وتنفيذ الأوامر،
  مع تسلسل بصري أوضح بين الأوامر والتنقل ومحتوى مساحة العمل.
- **تنقل متجاوب:** قائمة جانبية محسنة للحاسوب، ودرج تنقل متكيف لشاشات الجهاز
  اللوحي، ومدخل مباشر للأوامر في شريط الهاتف.
- **بحث وسير عمل أوضح:** تحسين البحث، الاقتراحات، التنقل، وصفحات الإعدادات، مع
  حفظ إرسال البحث بعد الاختيار.
- **جلسات موثوقة:** تمرير صحيح لملفات تعريف الارتباط عبر وكيل API ومعالجة
  رؤوس `Set-Cookie` المدمجة من الخدمة الخلفية.
- **صلاحيات التقارير:** تصدير تقارير الامتثال يفرض التفويض المطلوب.
- **جودة وإتاحة الوصول:** تغطية اختبارية موسعة للوحة المفاتيح، وإتاحة الوصول،
  والانحدار البصري عبر شاشات 375 و768 و1280 بكسل.

## التحقق المنفذ للمرشح

- اختبارات واجهة Next.js ووحداتها.
- فحص TypeScript وبناء Next.js.
- فحص أساسيات الأمان، واختبارات الإتاحة والوضع البصري الخاصة بالواجهة.

## حالة النشر

هذا **مرشح مصدر محلي** وليس GitHub Release منشورًا بعد. لا توجد حاليًا صور Docker
أو حزمة offline أو SBOM أو checksums تخص `v1.0.0-rc.2`. لا يُنشأ tag ولا تُنشر
artifacts قبل استكمال قبول RC الخارجي وسجل Go/No-Go ثم نجاح pipeline الإصدار.

## متطلبات قبل النشر الرسمي

- إغلاق عناصر RC الإلزامية في `TASKS.md`، وتشمل قياسات الأداء والإتاحة والقبول
  على المضيفات النظيفة.
- إرفاق أدلة Windows وLinux وDocker وNative لمسارات online وoffline.
- اعتماد Release Manager لسجل Go/No-Go.
- دفع tag `v1.0.0-rc.2` فقط بعد اكتمال ما سبق؛ عندها تنشئ GitHub Actions الصور
  الموقعة وحزمة offline وملفات SBOM وchecksum وGitHub prerelease تلقائيًا.
