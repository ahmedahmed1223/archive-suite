# مسار v1.0.0

[English](v1.0.0.md) · [فهرس التوثيق](../README.ar.md)

يقدّم الإصدار `v1.0.0` من مسار مساحة عمل موحّدة لإدارة المواد الأرشيفية
والوسائط. يشمل واجهة أوامر موحدة، وتنقلًا متجاوبًا، وتجربة بحث أوضح، وإدارة
موثوقة للجلسات عبر API، وتصدير تقارير ملتزم بالصلاحيات، ونسخًا احتياطيًا
واستعادة تتعاملان مع الأرشيفات الكبيرة، وتحسينات للإتاحة والجودة البصرية.

يدير المشرف التثبيت والصيانة والنسخ الاحتياطي والاستعادة من خلال Control Center.
راجع [فهرس التوثيق](../README.ar.md) للحصول على التعليمات الحالية.
