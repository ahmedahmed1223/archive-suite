# مسار v1.0.0

أول إصدار عام (GA) من **مسار**. تنطبق عليه نافذة الدعم الموصوفة في
[سياسة الإصدارات](../versioning.md) — إصلاحات وأمان كاملة لأحدث MINOR.

## أبرز ما تغير منذ `v1.0.0-rc.1`

- **واجهة Focus Command:** نقطة أوامر موحّدة للبحث وفتح الصفحات وتنفيذ الأوامر،
  مع تسلسل بصري أوضح بين الأوامر والتنقل ومحتوى مساحة العمل.
- **تنقل متجاوب:** قائمة جانبية محسنة للحاسوب، ودرج تنقل متكيف لشاشات الجهاز
  اللوحي، ومدخل مباشر للأوامر في شريط الهاتف.
- **بحث وسير عمل أوضح:** تحسين البحث والاقتراحات والتنقل وصفحات الإعدادات، مع
  حفظ إرسال البحث بعد الاختيار.
- **جلسات موثوقة:** تمرير صحيح لملفات تعريف الارتباط عبر وكيل API ومعالجة رؤوس
  `Set-Cookie` المدمجة من الخدمة الخلفية.
- **صلاحيات التقارير:** تصدير تقارير الامتثال يفرض التفويض المطلوب.
- **نسخ احتياطي يصمد على أرشيف حقيقي (V1-X05):** كان الإنشاء والاستعادة يحمّلان
  الأرشيف كاملًا في الذاكرة فيموتان على 1.1GB. صارت الكتابة تتدفّق عبر مقبض
  gzip بصيغة مُسطَّرة (`ndjson-v1`)، والقراءة تكشف الصيغة من أول 64 بايت فتبقى
  أرشيفات v2 والقديمة قابلة للاستعادة. الذروة 79 MB على نفس الحجم الذي كان
  يقتل الطرفين.
- **قبول التثبيت على Windows عبر Docker (V1-210D):** دورة
  `install --config=` ثم `update` ثم `rollback` بوصف إصدار موقَّع وصور موسومة
  `@sha256:`، نُفِّذت فعليًا على Windows 11 وكشفت وأصلحت 5 عيوب كانت تمنع مسار
  الإصدار الموقَّع من العمل.
- **تدريب الكوارث (V1-501):** 6 سيناريوهات عطل مُنفَّذة فعليًا (PostgreSQL،
  Redis، العامل، Reverb، عطل شبكي، امتلاء قرص) بحقن عطل حقيقي ثم كشف واستعادة
  وتحقق من سلامة البيانات.
- **جودة وإتاحة الوصول:** تغطية اختبارية موسعة للوحة المفاتيح وإتاحة الوصول
  والانحدار البصري عبر شاشات 375 و768 و1280 بكسل.

## التحقق المنفذ

بوابة الإصدار الكاملة `pnpm release:verify` على هذا الـcommit: قابلية إعادة
الإنتاج والصور غير القابلة للتغيير وسلسلة التوريد، افتراضات التحويل، عقد API
والارتباطات المولّدة منه، حدود استخراج الخدمات، فحص TypeScript، اختبارات وحدات
الواجهة، بناء Next.js، نظافة المستودع، اختبارات Laravel (PHPUnit)، ثم أساسيات
الأمان وتدقيق الاعتماديات وفحص جاهزية الإصدار.

## الحدود المعروفة

هذه القدرات تُشحن معطَّلة أو مشروطة، ولم يجرِ التحقق منها على بيئة حية:

- **ODBC حي على Windows (V1-X02):** يحتاج DSN/driver وبيانات اختبار على جهاز فعلي.
- **التفريغ العربي على GPU (V1-X03):** يحتاج عينة معتمدة وعتادًا مناسبًا.
- **AI/vision/embeddings الحية (V1-X04):** تحتاج مزودًا وفهرسًا حيَّين ومفاتيح
  محفوظة في secret manager؛ نقاط الربط موجودة لكن التشغيل الحي غير مُتحقَّق منه.
- **المسار المشفَّر للنسخ الاحتياطي يظل مخزَّنًا مؤقتًا في الذاكرة** لأن
  `Crypt::encrypt` يستقبل نصًا واحدًا ولا يقبل مجرى — الحد موثَّق صراحة في
  الشيفرة، وينطبق على النسخ المشفَّرة فقط.

**نطاق القبول:** صدر هذا الإصدار **دون** برنامج قبول رسمي متعدد المنصات
(V1-806–V1-814)، ودون تشغيل تجريبي وبروفة إصدار (V1-502–V1-505)، ودون سجل
Go/No-Go منفصل (V1-601–V1-605) — قرار منتج بتاريخ 2026-08-06. تبقى هذه البنود
مفتوحة ومحجوبة خارجيًا في [`TASKS.md`](../../TASKS.md)؛ أُزيلت قدرتها على حجب
البوابة فقط، لا وجودها. المنصات التي لا تحمل دليلًا مسجَّلًا تبقى `planned` أو
`conditional` في عقد التوافق ولا تدّعي الدعم.
