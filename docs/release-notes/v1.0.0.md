# Archive Suite v1.0.0

[العربية](v1.0.0.ar.md) · [Documentation](../README.md)

Archive Suite v1.0.0 is the general-availability release of the archive and media
workspace. It brings a unified command surface, responsive navigation, clearer
search workflows, reliable API session handling, permissioned compliance-report
exports, streamed archive backup and restore, and expanded accessibility and
visual-regression coverage.

Operators manage installation, maintenance, backup, and recovery through
Control Center. Read the [documentation index](../README.md) for current
installation, platform, and support guidance.
