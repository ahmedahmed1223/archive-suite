# مسار v1.1.0

[English](v1.1.0.md) · [فهرس التوثيق](../README.ar.md)

يوسّع الإصدار `v1.1.0` تجربة العمل العربية، ويقدّم مركز مساعدة ثنائي اللغة
بمعالجة أكثر أمانًا، ويدعم رسميًا التشغيل عبر Docker والتشغيل المباشر على
Windows وLinux. تشمل أصول الإصدار حزم Native متحققًا منها وأدلة قبول للمنصتين.

## أبرز التغييرات

- يمكن للمستخدم التبديل بين العربية والإنجليزية، ويحفظ النظام اللغة في حسابه.
  أصبحت الواجهة العامة وتسجيل الدخول والبحث والاستكشاف والنشاط والإشعارات
  والمزامنة والخريطة ومركز البيانات والتشغيل الأول تتبع هذا الإعداد.
- يعرض مركز المساعدة أدلة HTML محلية بحسب الصلاحية واللغة من خلال عارض ينقّي
  المحتوى، ويغطي مسارات عمل المشاهد والمحرر والمشرف.
- تبني أدوات Windows وLinux حزم تشغيل مباشر تضم إصدارات مثبتة من PHP وNode.js
  وCaddy، وترتبط بعمليات مركز التحكم ودورة حياة الخدمات والتشخيص والتنظيف.
- أصبح توثيق التثبيت والنشر والميزات والدعم وAPI والتشغيل متاحًا بنسختين
  عربية وإنجليزية، مع فحوص آلية للتصنيف والروابط.
- تصلح بوابة الإصدار اعتمادات تطوير Laravel القديمة قبل الاختبار، وتتحقق من
  توثيق نطاق كل مسار وصلاحياته.

## حالة المنصات

يدعم الإصدار Docker والتشغيل المباشر على Windows وLinux. يعمل مسار Windows
Native على Windows 10 و11، ويتطلب مسار Linux Native وجود `systemd`. لا تُنشر
أي حزمة Native قبل نجاح اختبار القبول على جهاز نظيف، وتحتوي كل حزمة سجل بصمات
مغلقًا يتيح التحقق من جميع ملفاتها.

يستخدم تفريغ Whisper البرنامج التنفيذي المعتمد `whisper-ctranslate2`. يمثل
التشغيل على CPU مع `int8` خط الأساس المتاح على أوسع نطاق. ويتطلب تشغيل CUDA
استيفاء متطلبات GPU الواردة في دليل Whisper، كما يتطلب فصل المتحدثين رمز
المزوّد والاعتمادات الموضحة بصورة مستقلة.

## الترقية

أنشئ نسخة احتياطية وتحقق منها قبل التحديث، ثم نفّذ ترحيلات قاعدة البيانات
المعتادة. يضيف هذا الإصدار إعداد لغة الحساب من دون تغيير الإصدار الرئيسي
لواجهة API. راجع [مصفوفة دعم المنصات](../platform-parity.ar.md) قبل اختيار
طريقة التثبيت.
