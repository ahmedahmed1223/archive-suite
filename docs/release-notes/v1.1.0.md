# Archive Suite v1.1.0

[العربية](v1.1.0.ar.md) · [Documentation](../README.md)

Archive Suite v1.1.0 expands the Arabic-first workspace, publishes a safer
bilingual help experience, and adds the packaging and acceptance foundations
for native Windows and Linux operation.

## Highlights

- The interface language can be changed between Arabic and English and is
  retained for the signed-in account. The shared shell, authentication,
  search, discovery, activity, notifications, sync, map, data-centre, and
  first-run surfaces now follow that preference.
- The in-app help centre serves authorised, localised HTML guides through a
  sanitised renderer, including workflows for viewers, editors, and
  administrators.
- Windows and Linux native bundle builders now stage pinned PHP, Node.js, and
  Caddy runtimes and integrate with Control Center lifecycle operations,
  service configuration, diagnostics, and cleanup.
- Public installation, deployment, feature, support, API, and operations
  documentation now has maintained English and Arabic editions with automated
  link and classification checks.
- Release verification now repairs stale Laravel development dependencies
  before running tests and enforces documented route scope and role coverage.

## Platform status

Docker on Windows and Linux remains the supported deployment path. The native
Windows and Linux entries remain `planned` in the platform compatibility
contract while their release evidence is completed. The new native builders
and diagnostics do not by themselves constitute a support declaration.

## Upgrade notes

Create and verify a backup before updating. Run the normal database migrations;
this release adds the account locale preference without changing the public API
major version. Review the [platform support matrix](../platform-parity.md) before
choosing an installation mode.
