# Archive Suite — الإصدار 1.2.0

[English](v1.2.0.md) · [التوثيق](../README.ar.md)

يغلق الإصدار 1.2.0 فجوات بوابات جودة CI المتروكة منذ 1.1.0، ويُصلح جسر
قواعد البيانات القديمة (ODBC) وتشفير النسخ الاحتياطية المتدفق، ويُفعِّل عدة
إعدادات أمنية كانت معروضة بلا أثر فعلي، ويضيف تحليلًا ساكنًا وفحص ثغرات لكل
طلب سحب (PR).

## أبرز التغييرات

- **تجربة الاستخدام:** تهيئة أول استخدام خطوة بخطوة مع استئناف المسار، وتنقل
  أوضح على الهاتف، وإعدادات مركزية لعرض المنطقة الزمنية والتاريخ والوقت.
- **متابعة الوسائط:** تعرض قائمة المهام تقدم المعالجة وحالة طابور CPU/GPU
  وحالة الاتصال المباشر، مع تحديث دوري آمن عند انقطاع البث.

- **بوابات الجودة:** Vitest و`verify:api-generated` و
  `verify:service-thresholds` تعمل الآن على كل PR بدل وسم الإصدار فقط.
  ESLint (`react-hooks/exhaustive-deps`) وLaravel Pint مثبَّتان ومُفعَّلان
  في CI.
- **جسر ODBC:** يُشحَن الآن بامتداد `odbc` مُثبَّتًا، ويولّد SQL مطابقًا
  للهجة الفعلية (SQL Server أو PostgreSQL أو MySQL عبر `ODBC_DIALECT`) بدل
  صياغة خاصة بـSQL Server فقط كانت تفشل بصمت على غيره. فشل الاستعلام
  الحقيقي يظهر الآن كخطأ صريح بدل أن يبدو كجدول فارغ.
- **تشفير النسخ الاحتياطية:** النسخ المشفَّرة تمر الآن عبر AES-256-GCM
  بقِطَع مصادَقة ثابتة الحجم بدل تحميل الأرشيف كاملًا في الذاكرة لاستدعاء
  `Crypt::encrypt()` واحد.
- **إعدادات أمنية فعّالة فعليًا:** سياسة أمان المحتوى (CSP) تُصدَر الآن
  بـnonce حقيقي لكل طلب (script-src لم يعد يحتاج `unsafe-inline`/
  `unsafe-eval`)، وسقف معدل الطلبات القابل للضبط يُطبَّق على كل مسارات
  API لا بضعة مسارات فقط، ومصادر CORS مربوطة فعليًا بوسيط Laravel بدل أن
  تكون للعرض فقط.
- **تحليل ساكن:** PHPStan (Laravel) وCodeQL (Next.js/TypeScript) يعملان
  الآن في CI؛ فحص ثغرات Trivy يعمل على كل PR بمستوى HIGH/CRITICAL لا عند
  الإصدار فقط.
- **فحص الصحة:** فحص صحة حاوية Next.js يتحقق الآن من الاتصال الفعلي
  بمنبع Laravel بدل الاكتفاء بالرد على صفحته الجذرية.

## قيود معروفة منتقلة لهذا الإصدار

- **دعم الإنجليزية جزئي:** تتيح الإعدادات اختيار الإنجليزية، لكن الدعم الكامل
  للإنجليزية لم يكتمل في الإصدار 1.2.0. قد تظهر نصوص عربية في بعض الصفحات
  والرسائل التشغيلية؛ العربية هي اللغة المدعومة بالكامل حاليًا.
- ما تزال نصوص الواجهة العربية مضمّنة مباشرة في أغلب الصفحات بدل المرور
  الكامل بطبقة القاموس المشتركة؛ توحيد التنقل/تسميات الصفحات محدَّد النطاق
  ولم يكتمل في هذا الإصدار.
- بوابة ميزانية الأداء (`docs/performance/runs/`) لم تسجّل خط أساس أول
  بعد؛ تحتاج عدّاء CI مطابقًا للملف التعريفي الموثَّق.
- تفريغ Whisper بتسريع GPU يحتاج صورة مبنية من قِبل المشغّل — صورة العامل
  المشحونة لا تحمل وقت تشغيل CUDA/cuDNN.
- اتصال ODBC بـSQL Server يحتاج طبقة سائق `msodbcsql` يضيفها المشغّل؛
  سائقا PostgreSQL وMySQL/MariaDB يُشحنان افتراضيًا.

راجع [`docs/known-limitations.ar.md`](../known-limitations.ar.md) للقائمة
الكاملة المُحدَّثة.

## ملاحظات الترقية

لا تغييرات كاسرة في API أو قاعدة البيانات. مشغّلو جسر ODBC ضد قاعدة غير
SQL Server يجب أن يضبطوا `ODBC_DIALECT` صراحة. المعتمدون على إعدادات
`csp_policy`/`cors_origins`/`rate_limit_per_minute` يجب أن يتأكدوا أن
السلوك المُفعَّل الآن فعليًا يطابق توقعاتهم قبل ترقية نشر إنتاجي.
