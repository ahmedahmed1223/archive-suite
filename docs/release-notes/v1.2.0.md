# Archive Suite v1.2.0

[العربية](v1.2.0.ar.md) · [Documentation](../README.md)

Archive Suite v1.2.0 closes CI quality-gate gaps left open since v1.1.0,
fixes the ODBC legacy-database bridge and streaming backup encryption, wires
several security settings that were displayed but never enforced, and adds
static analysis and vulnerability scanning to pull requests.

## Highlights

- **Everyday experience:** Guided first-use setup can be resumed, mobile
  navigation is clearer, and administrators can centrally set time-zone,
  date, and time display preferences.
- **Media-job tracking:** The jobs list shows processing progress, CPU/GPU
  queue status, and live connection state, with safe polling when broadcasts
  are unavailable.

- **Quality gates:** Vitest, `verify:api-generated`, and
  `verify:service-thresholds` now run on every pull request instead of only
  at release-tag time. ESLint (`react-hooks/exhaustive-deps`) and Laravel
  Pint are both installed and gated in CI.
- **ODBC bridge:** the legacy-database read/write bridge now ships with the
  `odbc` PHP extension installed, and generates dialect-correct SQL for
  SQL Server, PostgreSQL, or MySQL (`ODBC_DIALECT`) instead of SQL
  Server-only syntax that silently failed elsewhere. A real query failure
  now surfaces as an error instead of looking like an empty table.
- **Backup encryption:** encrypted backups now stream through AES-256-GCM in
  fixed-size authenticated chunks instead of loading the whole archive into
  memory for a single `Crypt::encrypt()` call.
- **Security settings, actually enforced:** Content-Security-Policy now
  ships with a real per-request nonce (script-src no longer needs
  `unsafe-inline`/`unsafe-eval`), the configurable per-user rate limit
  applies to every API route (not just a handful), and CORS origins are
  wired to Laravel's CORS middleware instead of being display-only.
- **Static analysis:** PHPStan (Laravel) and CodeQL (Next.js/TypeScript) now
  run in CI; Trivy vulnerability scanning runs on every pull request at
  HIGH/CRITICAL, not only at release time.
- **Health checks:** the Next.js container's health check now verifies it
  can actually reach its Laravel data upstream, instead of just answering
  its own root page.

## Known limitations carried into this release

- Arabic-first UI text still lives inline in most pages rather than fully
  through the shared dictionary layer; the navigation/page-label
  consolidation is scoped but not completed this release.
- The performance budget gate (`docs/performance/runs/`) has not recorded a
  first baseline; it requires a CI runner matching the documented profile.
- GPU-accelerated Whisper transcription requires an operator-built image
  variant — the shipped worker image has no CUDA/cuDNN runtime.
- SQL Server ODBC connectivity requires an operator-added `msodbcsql`
  driver layer; PostgreSQL and MySQL/MariaDB drivers ship by default.

See [`docs/known-limitations.md`](../known-limitations.md) for the full,
maintained list.

## Upgrade notes

No breaking API or database changes. Operators using the ODBC bridge against
a non-SQL Server backend should set `ODBC_DIALECT` explicitly. Operators
relying on `csp_policy`/`cors_origins`/`rate_limit_per_minute` settings should
confirm the now-enforced behavior matches their expectations before
upgrading a production deployment.
