# Archive Suite — الإصدار 1.2.1

[English](v1.2.1.md) · [التوثيق](../README.ar.md)

يستكمل الإصدار 1.2.1 دعم الواجهة الإنجليزية الذي كان جزئيًا في الإصدار
1.2.0. وهو إصدار صيانة مركّز لا يتضمن تغييرات على واجهة API أو قاعدة البيانات.

## أبرز التغييرات

- **دعم كامل للغتين:** أصبحت الإنجليزية متاحة في جميع أجزاء التطبيق، بما في
  ذلك الرسائل التشغيلية، ومسار التهيئة، والنصائح السياقية، والإشعارات، والرفع
  المجدول، وسير عمل السجلات، وفحوصات السلامة، ومصطلحات الأرشيف الافتراضية.
- **سير عمل مترابط بحسب اللغة:** تتبع تسميات الواجهة والاختصارات وتنسيق الوقت
  والحالات والإعداد الموجّه اللغة التي يختارها المستخدم.
- **تحقق خاص بالترجمة:** يكشف فحص آلي للنصوص أي نص واجهة عربي غير مترجم عند
  اختيار الإنجليزية. اكتملت اختبارات Next.js وLaravel وفحص الأنواع والبناء
  ونظافة المستودع لهذا الإصدار.

## ملاحظات الترقية

لا يلزم أي إجراء. تبقى عمليات التثبيت العربية الحالية كما هي، ويمكن للمستخدم
اختيار الإنجليزية من الإعدادات مع الحصول على مستوى المزايا نفسه.
