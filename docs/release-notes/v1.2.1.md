# Archive Suite v1.2.1

[العربية](v1.2.1.ar.md) · [Documentation](../README.md)

Archive Suite v1.2.1 completes the English interface work that was still
partial in v1.2.0. It is a focused maintenance release with no API or database
changes.

## Highlights

- **Full bilingual interface support:** English is now available throughout
  the product, including operational messages, onboarding, contextual tips,
  notifications, scheduled uploads, record workflows, safety checks, and
  default archive terminology.
- **Consistent localized workflows:** Interface labels, keyboard shortcuts,
  time and status formatting, and guided setup follow the active language.
- **Release-quality verification:** Automated localization coverage detects
  untranslated Arabic interface text when English is selected. The Next.js and
  Laravel test suites, type checks, build, and repository-hygiene checks were
  completed for this release.

## Upgrade notes

No action is required. Existing Arabic installations are unchanged; users can
select English from Settings and receive the same feature coverage.
