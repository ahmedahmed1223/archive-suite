# Archive Suite — الإصدار 1.3.0

[English](v1.3.0.md) · [التوثيق](../README.ar.md)

يقدّم الإصدار 1.3.0 منصة موحدة للإعدادات والتخصيص، واستوديو وسائط متكاملًا،
وتمكينًا لسير عمل الفِرق، وتحسينات ملموسة في الأداء والاعتمادية. تظل توسعات
قدرات الذكاء الاصطناعي مؤجلة، ولم تُضَف أي إعدادات وهمية لها.

## أبرز التغييرات

- **منصة إعدادات مخصَّصة:** مركز إعدادات واحد يجمع القدرات، وتجربتك
  الشخصية، وإعدادات الوسائط، والإشعارات، مع بيان واضح لمن يمكنه تغيير كل
  إعداد ولماذا. أربعة أنماط جاهزة حسب الدور (أمين أرشيف، مراجع، محرر وسائط،
  عرض مبسط) تتيح تطبيق تهيئة كاملة للتنقل والعرض بخطوة واحدة، مع إمكانية
  تخصيص ترتيب التنقل وأعمدة جدول الأرشيف وفلاتره بعد ذلك.
- **استوديو وسائط موحد:** افتح وسائط أي سجل في مساحة عمل واحدة تجمع المشغّل،
  وخطًا زمنيًا للتعليقات المؤقّتة بتصنيفات مشكلة/اقتراح/تمييز/فصل، ومحرر نص
  مفرَّغ وترجمة متزامنًا بسجل حفظ واستعادة وقفل تحرير، ومقارنة إصدارات جنبًا
  إلى جنب مع قوائم مقاطع غير هدّامة قابلة للتصدير بصيغتَي JSON وCSV، ونُسخًا
  مصغّرة (صورة مصغّرة، شكل موجي، معاينة) مخزَّنة مؤقتًا ومرتبطة بإصدار المصدر
  بالضبط.
- **مراجعة خارجية واعتماد:** شارك رابط مراجعة محدود المدة للوسائط خارج
  المؤسسة، بصلاحية تنزيل قابلة للتهيئة، وسياسة علامة مائية، وقرارات
  موافقة/طلب تعديلات مسجَّلة، مع دعم موافقة مراجعَين اختياريًا.
- **صندوق عمل موحد وقوالب سير عمل:** تظهر المهام والمراجعات والحقوق القريبة
  من الانتهاء في مكان واحد. تسرّع قوالب الأرشفة والمراجعة والإنتاج الإعداد
  المعتاد، ويمكن أن تحمل المهام مدة إنجاز مستهدفة مع تصعيد قابل للتهيئة
  إداريًا، ويمكن للمدير اشتراط موافقة ثانية مستقلة على العمليات الحساسة أو
  الجماعية — لا يمكن لمقدّم الطلب نفسه أن يقدّم تلك الموافقة الثانية أبدًا.
- **أدوات التصنيف والمفردات:** طبّق قوالب بيانات وصفية ووسوم جاهزة لأنماط
  الأرشيف الشائعة (برامج البث، اللقطات الميدانية، الشهادات الشفوية، التوثيق
  الحقوقي) مع معاينة قبل إنشاء أي شيء. تُعرَّف مصطلحات المفردات ومرادفاتها
  الآن تلقائيًا أينما ظهرت في نص السجلات.
- **الأداء والاعتمادية:** يربط تتبّع الطلبات المترابط الطلب البطيء عبر
  الواجهة والـAPI والمعالجة الخلفية. تعتمد نتائج البحث تخزينًا مؤقتًا ثابتًا
  وترفض النتائج القديمة غير المرتّبة زمنيًا، وتطبّق طوابير معالجة الوسائط
  ضغطًا خلفيًا مع إعادة محاولة وإلغاء آمنَين، وتحمّل عدة صفحات واجهة ثقيلة
  لوحاتها الأقل استخدامًا عند الحاجة فقط.
- **توثيق أعمق ومساعدة داخل التطبيق:** أدلة المستخدم والمدير والاستوديو
  ومعالجة الوسائط متاحة بالعربية والإنجليزية، إلى جانب مركز مساعدة داخل
  التطبيق موسَّع بشكل كبير.

## القيود المعروفة

راجع [القيود المعروفة](../known-limitations.ar.md) للقائمة الحالية، ومنها:
العلامة المائية للمراجعة الخارجية تراكب مرئي لا حرق فعلي في بكسل الوسيط؛
توليد المشتقات يعمل دائمًا على طابور المعالجة القياسي (التفريغ النصي فقط
يُوجَّه إلى GPU)؛ وصندوق العمل لا يطبّق بعد عزلًا قسميًا صارمًا على عنصر
الحقوق القريبة من الانتهاء.

## ملاحظات الترقية

كل تغييرات قاعدة البيانات في 1.3.0 ترحيلات إضافية بالكامل تعمل تلقائيًا أثناء
التحديث العادي — لا حاجة لأي ترحيل بيانات يدوي. تبقى الإعدادات والسجلات
والوسائط الحالية كما هي حتى تختار استخدام ميزة جديدة. راجع
[الترقية والاستعادة](../native-installation.ar.md#الترقية-والاستعادة) لإجراء
التحديث العام.
