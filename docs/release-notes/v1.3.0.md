# Archive Suite v1.3.0

[العربية](v1.3.0.ar.md) · [Documentation](../README.md)

Archive Suite v1.3.0 delivers a unified settings and personalization
platform, a complete media studio, workflow enablement for teams, and
measurable performance and reliability improvements. AI capability
expansion remains deferred; no placeholder configuration was added for it.

## Highlights

- **Personalized settings platform:** A single settings hub covers
  capabilities, your experience preferences, media defaults, and
  notifications, with clear indicators for who can change each setting and
  why. Four ready-made role presets (Archivist, Reviewer, Media Editor,
  Simple view) let you apply a complete navigation and view configuration in
  one step, and you can still customize navigation order and archive table
  columns and filters afterward.
- **Unified media studio:** Open any record's media into a single workspace
  combining the player, a timestamped comment timeline with issue/suggestion/
  highlight/chapter markers, a synchronized subtitle and transcript editor
  with save/restore history and edit locking, side-by-side version
  comparison with non-destructive clip lists exportable to JSON/CSV, and
  cached thumbnail/waveform/preview derivatives tied to the exact source
  version.
- **External review and approval:** Share a time-limited review link for
  media outside the organization, with configurable download permission, a
  watermark policy, and recorded approve/request-changes decisions,
  including optional two-reviewer approval.
- **Unified work inbox and workflow templates:** Tasks, reviews, and
  near-expiry rights surface in one place. Archive, review, and production
  templates speed up common setups, tasks can carry a target completion
  duration with admin-configurable escalation, and administrators can
  require a second, independent approval for sensitive or bulk operations —
  the original requester can never provide that second approval.
- **Classification and vocabulary tools:** Apply ready-made metadata and tag
  templates for common archive patterns (broadcast programs, field footage,
  oral testimony, rights documentation) with a preview before anything is
  created. Vocabulary terms and their synonyms are now recognized and
  explained inline wherever they appear in record text.
- **Performance and reliability:** Correlated request tracing connects a
  slow request across the interface, the API, and background processing.
  Search results use stable caching and reject stale out-of-order
  responses, media processing queues apply backpressure and support safe
  retry and cancellation, and several heavy interface pages now load their
  less-used panels on demand.
- **Deeper documentation and in-app help:** User, administrator, media
  studio, and media-processing guides are available in Arabic and English,
  alongside a substantially expanded in-app help center.

## Known limitations

See [Known limitations](../known-limitations.md) for the current list,
including: external review watermarking is a visible overlay rather than a
burned-in pixel mark; derivative generation always runs on the standard
processing queue (only transcription is GPU-routed); and the work inbox
does not yet apply strict per-department isolation to the near-expiry
rights item.

## Upgrade notes

All v1.3.0 database changes are additive migrations that run automatically
during a normal update — no manual data migration is required. Existing
settings, records, and media are unaffected until you choose to use a new
feature. See [Upgrade and recovery](../native-installation.md#upgrade-and-recovery)
for the general update procedure.
