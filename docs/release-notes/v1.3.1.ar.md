# Archive Suite — الإصدار 1.3.1

[English](v1.3.1.md) · [التوثيق](../README.ar.md)

يثبّت هذا الإصدار تجربة الاستخدام اليومية في مسار عبر الواجهتين العربية
والإنجليزية.

## أبرز التغييرات

- **اتجاه لغة صحيح:** يتبع اتجاه المستند اللغة النشطة في الصفحات المعروضة من
  الخادم وعند تغيير اللغة داخل الواجهة، فتظل العربية من اليمين إلى اليسار
  والإنجليزية من اليسار إلى اليمين.
- **قراءة أوضح على الهاتف:** تتكسر نصوص مقدمة تسجيل الدخول داخل المساحة
  المتاحة، وتمنع اختبارات الواجهة قص النص المقروء أو عناصر التحكم عند عروض
  375 و768 و1280 بكسل.
- **تحقق حقيقي لصفحة الرفع على الهاتف:** تتحقق بوابة Laravel وNext.js الحية
  من ظهور مساحة الرفع الفعلية للمحرر عند عرض 375 بكسل، لا من إعادة توجيه أو
  واجهة فارغة.
- **فحوص إصدار أكثر صرامة:** تتطلب جاهزية الإصدار تطابق نسخة الحزمة الجذرية
  مع حزمة Next.js، وتفشل بوضوح عند تعذر قراءة بيانات Git داخل مستودع حقيقي.

## ملاحظات الترقية

لا يغيّر هذا الإصدار عقد API أو مخطط قاعدة البيانات. انشره عبر مسار Docker
المعتاد أو مسار التحديث المباشر المدعوم.
