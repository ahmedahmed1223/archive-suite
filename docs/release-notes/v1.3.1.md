# Archive Suite v1.3.1

[العربية](v1.3.1.ar.md) · [Documentation](../README.md)

This maintenance release stabilizes everyday use of Archive Suite across
Arabic and English interfaces.

## Highlights

- **Correct language direction:** The document direction now follows the
  active locale in both server-rendered pages and client-side language
  switches, preserving Arabic RTL and English LTR layout.
- **Safer small-screen reading:** Login hero copy now wraps within the
  available width, and visual regression checks reject clipped readable text
  as well as clipped interactive controls at 375, 768, and 1280 pixels.
- **Real mobile uploads coverage:** The live Laravel + Next.js gate now
  verifies that an editor sees the actual uploads workspace on a 375px
  viewport, rather than a redirect or empty shell.
- **Stricter release checks:** Release readiness now requires the root and
  Next.js package versions to match, and fails clearly when Git metadata is
  unavailable inside a repository.

## Upgrade notes

This release changes no API contract or database schema. Deploy it through
the normal Docker or supported native update path.
