# Archive Suite — الإصدار 1.4.0

[English](v1.4.0.md) · [التوثيق](../README.ar.md)

يجدّد هذا الإصدار تجربة الاستخدام اليومية في مسار: تنقّل يومي ثابت حسب الدور،
وغلاف أبسط مع درج مسارات واضح، وعقد تفاعل موحّد على كل الصفحات. التنقل اليومي
الجديد يضع صندوق العمل في مقدمة وجهات أمين الأرشيف.

## أبرز التغييرات

- **تنقل يومي ثابت:** يبدأ كل دور (مشاهد، محرر، مسؤول) يومه بمجموعة ثابتة من
  أربع وجهات يومية تحترم الصلاحيات والإخفاءات.
- **غلاف أهدأ:** فصلنا إجراءات الغلاف عن درج المسارات مع تسلسل إجراءات قابل
  للوصول على الهاتف وسطح المكتب.
- **صندوق العمل نقطة بداية أمين الأرشيف:** ترتيب `/work-inbox` المهام العاجلة
  أولًا وأصبح المدخل اليومي الافتراضي لأمين الأرشيف.
- **حالات موحّدة للصفحات:** التحميل والفراغ والخطأ وإعادة المحاولة تُعرض عبر
  عقد واحد (`AsyncStateSurface`) في الأرشيف والبحث.
- **فلاتر متدرجة:** تبقى الفلاتر الأساسية ظاهرة وتنتظر الخيارات المتقدمة خلف
  إفصاح دلالي (`DisclosureToolbar`).
- **الرفع أولًا:** رفع الملف هو مسار الإدخال الأولي، وتبقى المسارات الثانوية
  (سجل بلا ملف، استيراد من رابط، قوالب، روابط) خلف إفصاح واحد. تبنّى الاستوديو
  والإعدادات حالات الغلاف نفسها.
- **تغطية تفاعلية لكل المسارات:** كل صفحة تنتمي إلى مجموعة تجربة ويُختبرها
  بدور وحالة صالحين — 65 مسارًا مصنّفة في `ROUTE_COVERAGE` دون فجوات صامتة.
- **جودة ثنائية اللغة وتخطيط مرن:** بوابات آلية تكشف أي تسمية إنجليزية غير
  مترجمة في العربية وأي نص عربي متسرب إلى الإنجليزية؛ أوراق الأنماط المشتركة
  تستخدم الخصائص المنطقية فقط، فيبقى RTL/LTR صحيحًا عند 375 و768 و1280 بكسل
  وعند تكبير 200% (عرض 640 بكسل).

## ملاحظات الترقية

لا يغيّر هذا الإصدار عقد API أو مخطط قاعدة البيانات. انشره عبر مسار Docker
المعتاد أو مسار التحديث المباشر المدعوم.
