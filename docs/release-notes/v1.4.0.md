# Archive Suite v1.4.0

[العربية](v1.4.0.ar.md) · [Documentation](../README.md)

This release refreshes the daily user experience of Archive Suite: stable
role-based daily navigation, a simpler shell with a clear navigation drawer,
and a unified interaction contract across every page.

This is the corrected reissue of v1.4.0 after the release gate and its page
test setup were brought into alignment.

## Highlights

- **Stable daily navigation:** Every role (viewer, editor, admin) lands on a
  consistent set of four daily destinations, respecting permissions and hidden
  records, so the working day starts in the same place every time.
- **A calmer shell:** Header actions are separated from the route drawer with
  an accessible action order on phone and desktop.
- **The work inbox as the archivist's starting point:** `/work-inbox` orders
  urgent tasks first and is now the default daily entry for archivists.
- **Unified page states:** Loading, empty, error, and retry are rendered by
  one `AsyncStateSurface` contract across archive and search.
- **Progressive filters:** Essential filters stay visible; advanced options
  wait behind a semantic disclosure (`DisclosureToolbar`).
- **Upload-first intake:** File upload is the primary intake path; secondary
  intake routes (fileless record, URL import, templates, links) wait behind
  one disclosure. The media studio and settings adopt the same shell states.
- **Interactive coverage for all routes:** Every App Router page belongs to an
  experience group and is tested with a valid role and state — 65 routes
  classified in `ROUTE_COVERAGE` with no silent gaps.
- **Bilingual quality and flexible layout:** Automated copy gates catch
  untranslated English labels in Arabic and Arabic leakage into English;
  shared stylesheets use logical properties only, so RTL/LTR switching stays
  correct at 375/768/1280 pixels and at 200% zoom (640px viewport).

## Upgrade notes

This release changes no API contract or database schema. Deploy it through
the normal Docker or supported native update path.
