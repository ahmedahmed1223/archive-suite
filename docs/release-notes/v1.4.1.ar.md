# Archive Suite — الإصدار 1.4.1

[English](v1.4.1.md) · [التوثيق](../README.ar.md)

يصدر هذا التحديث الصياني تجربة الاستخدام اليومية المكتملة في الإصدار 1.4،
بعد إدراج وثائق الإصدار بصورة صحيحة في سجل التوثيق العام.

## أبرز التغييرات

- **تحقق موثوق من الإصدار:** صُنّفت ملاحظات الإصدار ودليل تصميم تجربة
  الاستخدام صراحةً في سجل التوثيق، لتتحقق بوابة الإصدار من مجموعة الوثائق
  المنشورة كاملةً.
- **اللمسات الأخيرة للتجربة اليومية:** يتضمن إغلاق ملاحظات تدقيق الإصدار
  1.4 في التعاون والمكتبة والإدارة والخط الزمني واستعادة كلمة المرور.

## ملاحظات الترقية

لا يغيّر هذا الإصدار عقد API أو مخطط قاعدة البيانات. انشره عبر مسار Docker
المعتاد أو مسار التحديث المباشر المدعوم.
