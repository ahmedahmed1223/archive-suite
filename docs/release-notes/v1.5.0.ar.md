# Archive Suite — الإصدار 1.5.0

[English](v1.5.0.md) · [التوثيق](../README.ar.md)

يحسّن الإصدار 1.5 سير العمل اليومي والبحث وبيئة المونتاج غير الخطي. ويضيف
عقد API ومخططات قاعدة بيانات لمراجعات مشاريع المونتاج والتصدير الدائم.

## أبرز التغييرات

- **العمل اليومي في مكان واحد:** يجمع صندوق العمل المهام بحسب موعد
  الاستحقاق، ويحفظ تفضيلات مساحة العمل المحلية غير الحساسة لكل مستخدم مصادق
  عليه.
- **متابعة آمنة:** يتيح شريط الأوامر متابعة مساحة عمل حديثة فقط عند تفعيل
  تسجيل السياق الشخصي، ويمكن إخفاء الاقتراح خلال جلسة المتصفح الحالية.
- **بحث أوضح:** أصبحت أولوية حالة البحث بين الرابط والبحث المحفوظ والحالة
  المحلية حتمية، ويمكن إزالة الفلاتر النشطة مباشرةً، وتظهر معاينة النتيجة
  ضمن منطقة مسماة تدعم التقنيات المساعدة.
- **فحوص واجهة متسقة:** تغطي بوابات الإصدار الأدوات المشتركة واتجاه RTL/LTR
  والتجاوب وإتاحة الوصول والتكامل الحي بين Laravel وNext.js.
- **مونتاج بإصدارات محفوظة:** يمكن للمحرر إضافة مواد مثبتة إلى الخط الزمني،
  وحفظ مراجعات غير قابلة للتعديل، وتشغيل فحص قبل التصدير، ثم طلب تصدير من
  قائمة إعدادات مسموحة. وتظهر أعمال المعالجة والتصدير في صندوق العمل.

## ملاحظات الترقية

شغّل ترحيلات Laravel المرفقة قبل نشر التحديث. انشره عبر مسار Docker المعتاد
أو مسار التحديث المباشر المدعوم. تبقى حالة مساحة العمل داخل المتصفح ومقيدة
تلقائيًا بالمستخدم المصادق عليه.
