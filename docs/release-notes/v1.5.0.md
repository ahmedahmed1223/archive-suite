# Archive Suite v1.5.0

[العربية](v1.5.0.ar.md) · [Documentation](../README.md)

Archive Suite 1.5 improves daily operational work, search, and the non-linear
editing workspace. It adds versioned montage APIs and database migrations for
durable project revisions and export processing.

## Highlights

- **Daily work, in one place:** The work inbox groups due work clearly and
  remembers non-sensitive local workspace preferences per authenticated user.
- **Safe resume:** The command surface can resume a recent workspace only when
  personal-context recording is enabled. The suggestion can be dismissed for
  the current browser session.
- **Clearer search:** Search state has deterministic URL, saved, and local
  precedence; active constraints can be removed directly; result previews use
  a labelled live region for assistive technology.
- **Consistent UI checks:** Shared page tools, RTL/LTR behavior, responsive
  layouts, accessibility, and Laravel/Next.js live integration are covered by
  the release verification gates.
- **Versioned montage:** Editors can add pinned materials to a timeline, save
  immutable revisions, run a pre-export check, and request an allowlisted
  export. Processing and export work also appears in the work inbox.

## Upgrade notes

Apply the bundled Laravel migrations before deploying the application update.
Deploy through the normal Docker or supported native update path. Browser
workspace state remains local and is automatically scoped to the authenticated
user.
