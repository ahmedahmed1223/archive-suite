# Archive Suite — الإصدار 1.5.1

[English](v1.5.1.md) · [التوثيق](../README.ar.md)

يضيف الإصدار 1.5.1 مسار الحزم الأول الجاهز للإصدار للتشغيل المباشر دون حاويات
على Windows x64 وLinux x64. تتضمن حزمة كل منصة التطبيق وأوقات التشغيل المثبتة
وملفات التثبيت والإدارة ومصادر Control Center وبيانات الإصدار والبصمات ودليل
المشغل.

## أبرز التغييرات

- **نقطة تثبيت Native:** يشغّل `install.bat` أو `install.sh` مسار Control Center
  المناسب للمنصة بعد فك الحزمة.
- **إدارة Native:** تمرر `manage.bat` و`manage.sh` أوامر الحالة والصحة والسجلات
  والنسخ الاحتياطي والاستعادة والتحديث وإلغاء التثبيت، من خلال مسار إدارة واحد.
- **خدمات البيانات المضمنة:** يهيئ تثبيت Native الافتراضي PostgreSQL، ويثبت
  ملفات `pgvector` المتحقق منها، وينشئ حساب التطبيق، ويسجل خدمة Redis المتوافقة
  المضمنة. وتدخل هذه الخدمات في دورة الحياة وملكية إلغاء التثبيت.
- **إصدار قابل للتحقق:** تحتوي كل حزمة على `RELEASE.json` وسجل `SHA256SUMS`
  مغلق، وتنشر صفحة الإصدار البصمات الإجمالية وأدلة القبول على جهاز نظيف.
- **استعادة الحزمة غير المتصلة:** تتضمن أصول Docker المقسمة أوامر التجميع
  الدقيقة في Windows CMD وLinux/macOS، وبصمة مستقلة للأرشيف بعد تجميعه.

## ملاحظات الترقية

اقرأ دليل منصتك قبل التثبيت. تحقق من أصل الإصدار الذي نزّلته، واحتفظ بالتثبيت
السابق وبنسخة احتياطية تم التحقق منها حتى تجتاز النسخة الجديدة فحص `health`
وتجربة فعلية للبحث والرفع ومعالجة الوسائط. تُرفض أصول خدمات البيانات إذا غاب
مصدرها أو اختلفت بصمتها؛ لا تستبدلها بملفات تنفيذية غير موثقة.
