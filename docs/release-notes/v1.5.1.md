# Archive Suite v1.5.1

[العربية](v1.5.1.ar.md) · [Documentation](../README.md)

Archive Suite 1.5.1 adds the first release-ready Native Standalone packaging
path for Windows x64 and Linux x64. Each platform bundle contains the
application, pinned runtimes, platform launchers, Control Center sources,
release metadata, checksums, and operator documentation.

## Highlights

- **Native installer entry points:** `install.bat` and `install.sh` start the
  platform-specific Control Center flow from the extracted bundle.
- **Native management:** `manage.bat` and `manage.sh` forward status, health,
  logs, backup, restore, update, and uninstall commands without a second
  lifecycle implementation.
- **Bundled data services:** the default Native install initializes PostgreSQL,
  installs verified pgvector files, creates the application role, and registers
  the bundled Redis-compatible service; these services are included in Native
  lifecycle and uninstall ownership.
- **Verifiable release:** every bundle carries `RELEASE.json` and a closed
  `SHA256SUMS` inventory. The release page also publishes aggregate checksums
  and clean-host acceptance evidence.
- **Offline archive recovery:** split offline Docker assets include exact
  Windows CMD and Linux/macOS reconstruction commands and a separate digest
  for the reconstructed archive.

## Upgrade notes

Read the platform guide before installing. Verify the downloaded release asset
and preserve the previous installation and a verified backup until the new
version passes `health` and a representative search, upload, and media check.
Native data-service payloads are release inputs and are rejected when their
source or checksum is missing; do not replace them with unverified binaries.
