# Archive Suite v1.5.2

## أداة التثبيت والإدارة

- أصل مستقل لـ Windows: `Archive-Suite-Installer-Windows.zip`.
- أصل مستقل لـ Linux x64: `archive-suite-installer-linux.tar.gz`.
- Node.js مضمن داخل الأداتين، ومعالج تفاعلي لفحص البيئة واقتراح Docker أو Native مع إبقاء الاختيار للمستخدم.
- دعم أصول Offline المحلية، والتحقق من الأجزاء ودمجها دون تحميل الأرشيف كاملًا إلى الذاكرة.
- إعداد المدير والأسرار ومسار التخزين، وأوامر الحالة والتشغيل والإيقاف والسجلات والفحص والإصلاح والنسخ الاحتياطي.
- الحفاظ على بيانات التثبيت عند الإصلاح؛ الملفات التنفيذية والأصول تخضع لفحص SHA256.

ابدأ من [دليل أداة التثبيت والإدارة](../installer-manager.ar.md). تبقى حزم Native وOffline الكاملة متاحة ضمن أصول الإصدار.
