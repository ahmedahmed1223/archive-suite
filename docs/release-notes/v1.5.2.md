## Standalone installer and manager

Windows and Linux x64 installer assets include the pinned Node runtime. The Arabic wizard assesses host readiness, recommends Docker or Native, accepts a user's explicit choice, and configures first-run credentials and storage.

Verified local offline parts can be combined and installed without downloading images. Lifecycle commands cover status, start, stop, restart, logs, health, repair and backup through the existing runtime adapters. Repair preserves data. See the [operator guide](../installer-manager.ar.md) for requirements, commands and recovery limitations.
