# Archive Suite v1.5.3

[English](v1.5.3.md)

## تحسين تجربة أداة التثبيت في الطرفية

- أصبحت جميع رسائل التثبيت والإدارة داخل الطرفية باللغة الإنجليزية ومتوافقة مع الطرفيات القديمة.
- تستخدم المسارات التفاعلية قوائم مرقمة تعمل في PowerShell وCommand Prompt وطرفيات Linux.
- تظهر ألوان الحالة في الطرفيات التفاعلية فقط، ويمكن تعطيلها بضبط `NO_COLOR=1`.
- تشرح الأداة أخطاء الاختيار وبريد المدير وكلمة المرور والمنفذ، ثم تطلب الإدخال مجددًا قبل متابعة التثبيت.
- تُنقّى القيم التي يعرضها المستخدم لمنع حقن محارف التحكم في الطرفية.
- تتضمن أرشيفات أداة التثبيت الدليلين `README.md` و`README.ar.md`.

يستمر الإصدار في توفير أداتي Windows وLinux، وحزم Native، وأجزاء Offline المتحقق منها، وملفات البصمات، وقوائم مكونات البرمجيات، وأدلة الإصدار.
