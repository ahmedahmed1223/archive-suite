# Archive Suite v1.5.3

[العربية](v1.5.3.ar.md)

## English terminal installer experience

- All installer and management terminal messages are now English and terminal-safe.
- Interactive workflows use numbered menus that work consistently in PowerShell, Command Prompt, and Linux terminals.
- Status colors are enabled only for interactive terminals and can be disabled with `NO_COLOR=1`.
- Invalid menu selections, administrator credentials, and port values are explained and requested again before installation continues.
- User-provided terminal values are sanitized against control-sequence injection.
- Installer archives include both `README.md` and `README.ar.md`.

The release continues to provide Windows and Linux installer archives, Native packages, verified Offline parts, checksums, SBOMs, and release evidence.
