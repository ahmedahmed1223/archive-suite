# Archive Suite v2.0.0

[English](v2.0.0.md)

## التشغيل والوسائط

- أُضيف مسار تشغيلي موحد لدفعات الإدخال ومعالجة الوسائط والفحص التقني وQC
  والمشتقات والمهام المرتبطة.
- أصبحت تمثيلات الوسائط مثبتة على هوية الإصدار. لا تُعرض المشتقة القديمة
  بوصفها حالية، ولا يمكن بثها بوصفها الوسيط الحالي.
- أُضيفت نتائج بحث زمني تفتح التفريغ والوصف عند لحظتهما المسجلة، بدل حساب
  الزمن من معدل إطارات مفترض.

## المراجعة العامة والحقوق

- تعيد روابط المراجعة الخارجية التحقق من قرار الإتاحة العامة عند كل طلب
  للوسيط.
- الرابط الذي يطلب علامة مائية مرئية لا يبث إلا `review_proxy` منخفضة الجودة
  وجاهزة ومطابقة للإصدار، حُفرت علامتها داخل الفيديو بواسطة العامل. ولا يعود
  أبدًا إلى الأصل أو إلى نسخة عرض عادية.
- يمكن الآن إدارة نوافذ الحقوق داخل المنتج. يظهر القيد الذي حسم القرار،
  وتُسجَّل قرارات الرفض في سجل التدقيق، بما فيها رفض طلبات التوصيل القرائية.

## الاعتمادية والنزاهة

- تعرض حالة الخدمات والطوابير الأعطال القابلة للإجراء، وتتيح إعادة معالجة
  مضبوطة عندما تقبل العملية إعادة المحاولة.
- تعرض أسطح الحفظ والاستعادة والنزاهة الحالة المهيأة فعليًا، ولا تسمّي المصدر
  أو نسخة العرض نسخة حفظ.

## محتويات الإصدار

يبقى مسار Docker المدعوم متاحًا، إلى جانب أرشيفات التثبيت لـWindows وLinux
وحزم Native وأجزاء Offline المتحقق منها وملفات البصمات وقوائم المكونات وأدلة
الإصدار. تنشئ GitHub Actions العناصر المنشورة وتوقّعها من وسم `v2.0.0`.
