# Archive Suite v2.0.0

[العربية](v2.0.0.ar.md)

## Archive operations and media

- Added a unified operational flow for intake batches, media processing,
  technical inspection, QC, derivatives, and linked work items.
- Media representations are version-pinned. A stale derivative is neither
  presented as current nor streamable as current media.
- Added time-aware search results that open transcripts and descriptions at
  their recorded moments instead of calculating time from an assumed frame
  rate.

## Public review and rights

- External review links re-check live public rights on every media request.
- A visible-watermark link streams only a current, ready low-resolution
  `review_proxy` whose watermark is burned into the video by the worker. It
  never falls back to a source file or an ordinary proxy.
- Rights windows can now be managed in the product. Decisions show the
  deciding restriction and are recorded in the audit trail, including
  read-only delivery refusals.

## Reliability and integrity

- Service and queue status report actionable failures and permit a controlled
  retry where the underlying work is retryable.
- Preservation, recovery, and integrity surfaces report the actual configured
  state. They do not represent a source or access proxy as a preservation copy.

## Release contents

This release continues to provide the supported Docker path together with
Windows and Linux installer archives, Native packages, verified Offline parts,
checksums, SBOMs, and release evidence. Published artifacts are created and
signed by the GitHub release workflow from the `v2.0.0` tag.
