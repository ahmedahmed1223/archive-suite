# V1-303D — دليل إثبات قارئ الشاشة

الحالة: **بانتظار تنفيذ بشري**. وجود اختبارات Playwright لا يثبت تجربة قارئ الشاشة الفعلية، ولا يجوز إغلاق المهمة قبل إرفاق نتائج هذه العينة.

## النطاق

نفّذ العينة على أحدث بيئة Laravel + Next.js المرشحة للإصدار، بحساب الدور الذي تقتضيه الصفحة، ودوّن المتصفح وقارئ الشاشة وإصدار نظام التشغيل:

| الرحلة | المطلوب إثباته | النتيجة | الملاحظات/رابط الدليل |
| --- | --- | --- | --- |
| onboarding (`/first-run`) | رابط التخطي أول موضع Tab، ثم إعلان الانتقال وقراءة العنوان | بانتظار | |
| archive (`/archive`) | قراءة عنوان الصفحة، نتائج البحث، وفتح/إغلاق لوحة الأوامر بـ Escape مع رجوع التركيز | بانتظار | |
| record (`/archive/:id`) | قراءة عنوان السجل وأقسام التفاصيل والتنقل بلوحة المفاتيح | بانتظار | |
| upload (`/uploads`) | تسمية منطقة الإسقاط وإعلان بدء/تقدم/نجاح أو فشل الرفع مرة واحدة | بانتظار | |
| search (`/search`) | تسمية حقول البحث وإعلان حالة النتائج أو الخطأ مرة واحدة | بانتظار | |
| admin (`/settings/users` أو `/system/control`) | قراءة عناصر الإدارة المسمّاة والتنقل وEscape للحوارات | بانتظار | |

## إجراء العينة

1. استخدم NVDA مع Firefox أو VoiceOver مع Safari، وسجل الإصدارات وتاريخ التنفيذ.
2. ابدأ من تحميل جديد لكل رحلة، واضغط Tab حتى رابط «الانتقال إلى المحتوى الرئيسي»، ثم Enter.
3. افتح لوحة الأوامر من زر «فتح لوحة الأوامر»، وتحقق أن Tab لا يغادر الحوار، ثم اضغط Escape وتحقق من رجوع التركيز إلى الزر.
4. نفّذ الإجراء الخاص بالرحلة، واستمع إلى المنطقة الحية `polite`. يجب أن يكون الإعلان مفهومًا وغير مكرر.
5. احفظ لقطة شاشة أو تسجيلًا خاليًا من بيانات السجلات أو رموز الجلسة، واربطه في الجدول.

## حدود الدليل الآلي

يغطي Playwright ترتيب Tab، رابط التخطي، حبس تركيز حوار الأوامر، Escape وسمات `aria-live` في `archive-next/e2e/keyboard-navigation*.spec.ts`. لا يحل محل اختبار قارئ الشاشة البشري أعلاه.
