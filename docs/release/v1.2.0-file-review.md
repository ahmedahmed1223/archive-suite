# REL-1201 — مراجعة ملفات إصدار 1.2.0

تاريخ المسح: 2026-08-13. هذه قائمة مراجعة فقط؛ لم يُحذف أي ملف.

## مرشحات لا تدخل في الإصدار

| المسار أو النمط | القرار المقترح | السبب |
| --- | --- | --- |
| `performance-run*.log` و`performance-run*.err.log` | احتفظ بها محلياً أو انقلها إلى دليل أدلة منفصل | مخرجات تشغيل مؤقتة، وليست وثائق إصدار أو مصدراً. |
| `gpu-worker-build.log` و`gpu-worker-build.err.log` | احتفظ بها محلياً أو انقلها إلى دليل أدلة منفصل | سجل بناء محلي مؤقت. |
| `archive-next/debug.log` | احذف محلياً بعد تأكيد المالك | سجل تشخيص محلي. |
| `archive-laravel/storage/logs/laravel.log` | لا يضاف إلى Git؛ دوّره محلياً وفق سياسة التشغيل | سجل تشغيل خاص بالبيئة. |
| `archive-laravel/database/database.sqlite` | لا يضاف إلى Git؛ أعد إنشاؤه محلياً عند الحاجة | قاعدة اختبار/تطوير محلية. |

## النتيجة

لم تظهر ملفات ثنائية أو أرشيفات أو نسخ احتياطية متتبعة في Git ضمن المسح. لا
يجوز حذف أي مرشح أعلاه قبل اعتماد مالك المستودع؛ والقرار لا يغيّر مكونات
الإصدار أو ملفات المستخدم العامة.
