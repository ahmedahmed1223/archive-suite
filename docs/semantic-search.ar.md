# البحث الدلالي باستخدام pgvector

[English](semantic-search.md) · [فهرس التوثيق](README.ar.md)

يطلب `GET /api/v1/search?semantic=true` أقرب النتائج دلاليًا عندما تتوفر
الفهارس والتضمينات. لا يفشل البحث عند غيابها؛ يعود إلى البحث بالكلمات وتوضح
`facets.mode` ما حدث:

- `semantic`: نُفذ بحث دلالي فعليًا.
- `keyword-fallback`: طُلب البحث الدلالي لكنه لم يكن متاحًا، فنُفذ بحث بالكلمات.
- `keyword`: لم يُطلب البحث الدلالي.

يحتاج التشغيل الحي إلى مزود وتضمينات وإعدادات موثوقة. لا تفسر `semantic=true`
بوصفه ضمانًا لنتائج دلالية ما لم تكن الحالة `semantic`.
