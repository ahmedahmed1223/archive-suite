# البحث الدلالي باستخدام pgvector

[English](semantic-search.md) · [فهرس التوثيق](README.ar.md)

ينفّذ `GET /api/v1/search?semantic=true` بحثًا عن أقرب السجلات دلاليًا عبر
pgvector. إذا تعذر تنفيذ البحث الدلالي، يعود الطلب بأمان إلى البحث بالكلمات.
يوضح الحقل `facets.mode` المسار الذي استُخدم:

- `semantic`: نُفذ بحث دلالي فعلي.
- `keyword-fallback`: طُلب البحث الدلالي، لكن النظام استخدم البحث بالكلمات.
- `keyword`: لم يطلب العميل البحث الدلالي.

## المتطلبات

يعمل البحث الدلالي عندما تتحقق الشروط الآتية:

1. تستخدم قاعدة البيانات PostgreSQL.
2. تكون إضافة `vector` مثبتة؛ ينشئها ترحيل `record_embeddings` تلقائيًا.
3. تكون قيمة `EMBEDDINGS_ENABLED=true`.
4. يتوفر مفتاح مزود التضمينات، مثل `OPENAI_API_KEY`.

عند غياب أي شرط، يتوقف توليد التضمينات ويستمر البحث بالكلمات دون تعطيل البحث.

## متغيرات البيئة

| المتغير | القيمة الافتراضية | الغرض |
| --- | --- | --- |
| `EMBEDDINGS_ENABLED` | `false` | تشغيل التضمينات أو إيقافها |
| `EMBEDDINGS_PROVIDER` | `openai` | اسم المزود المستخدم |
| `EMBEDDINGS_MODEL` | `text-embedding-3-small` | نموذج التضمينات |
| `EMBEDDINGS_DIMENSIONS` | `1536` | عدد الأبعاد، ويجب أن يطابق عمود `vector(N)` |
| `EMBEDDINGS_BASE_URL` | `https://api.openai.com/v1` | عنوان طرفية متوافقة مع OpenAI |
| `OPENAI_API_KEY` | غير مضبوط | مفتاح مزود التضمينات |

احفظ المفتاح في مخزن أسرار، ولا تضعه في المستودع.

## إنشاء تضمينات للسجلات الحالية

```bash
php artisan embeddings:sync --store=records
```

يمر الأمر على سجلات المخزن المحدد، ويستخرج النصوص المفيدة، ويحدّث تضمين السجل
عند تغير المحتوى. يتجاوز السجلات التي لم تتغير، ويعرض ملخصًا بعدد السجلات
المعالجة والمحدّثة والمتجاوزة.

## سلوك النتائج

ينفّذ البحث مرورًا واحدًا لأقرب الجيران باستخدام مسافة جيب التمام وفهرس HNSW.
يرتب مجموعة النتائج حسب التشابه المتجهي، ولا يدمج الدرجة مع صلة الكلمات. استخدم
`facets.mode` لإظهار نوع البحث الذي أنتج النتائج.
