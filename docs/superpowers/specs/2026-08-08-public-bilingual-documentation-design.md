# تصميم تحديث التوثيق العام ثنائي اللغة

## الهدف

جعل التوثيق المنشور في مستودع **مسار** دقيقًا وقابلًا للاكتشاف ومتاحًا بالعربية
والإنجليزية، بحيث يستطيع المستخدم أو المشرف أو المساهم بدء العمل من الصفحة
المناسبة دون الاعتماد على وثائق تاريخية أو شيفرة المصدر لتفسير الأساسيات.

## النطاق والحدود

يشمل العمل الوثائق الحية المخصصة للجمهور العام أو لمشغلي النظام أو للمساهمين:

- صفحة البداية، دليل النشر، وأدلة التثبيت والتشغيل.
- صفحة فهرس للتوثيق العام، وأدلة الميزات والمستخدم والمشرف.
- توثيق المعمارية، عقد API، الإعدادات، المراقبة، التخزين، والنسخ الاحتياطي.
- صفحات Laravel وNext.js التي يراها من يتصفح المستودع مباشرة.
- ملاحظات الإصدار والدعم، مع توضيح حالة المنتج وحدود القدرات المشروطة.

لا يعاد تحرير الأدلة، تقارير القبول، سجلات الأعطال، أو خطط ومواصفات التنفيذ
التاريخية في `docs/evidence/` و`docs/superpowers/` و`docs/agent-batches/`.
تبقى هذه ملفات مرجعية مقيدة بتاريخها، ويضاف إليها وصف حالة فقط إذا كان ذلك
ضروريًا لمنع الخلط بينها وبين الأدلة الحية.

## بنية اللغتين

تكون الإنجليزية هي الصفحة الافتراضية التي تعرضها GitHub في الجذر، وتكون العربية
في ملف شقيق يحمل اللاحقة `.ar.md`. يتضمن رأس كل صفحة حية رابطَي تبديل لغة واضحين:

```text
English | العربية
```

يطبق ذلك على دليل البداية وفهرس التوثيق والأدلة الطويلة. لا تخلط الفقرات بين
اللغتين؛ الاستثناءات الوحيدة هي الأسماء التقنية التي لا ينبغي ترجمتها، مثل
`pnpm`, `Docker`, مسارات الملفات، أو مسارات API. العربية تلتزم بالاتجاه RTL
وبالمصطلحات المعتمدة في `docs/arabic-ui-glossary.md`.

## هيكل المحتوى

1. **البدء والاكتشاف:** يقدّم `README.md` و`README.ar.md` تعريف المنتج، حالة
   الإصدار الفعلية، المتطلبات، تشغيلًا محليًا قصيرًا، وروابط صريحة إلى الأقسام
   التالية.
2. **فهرس التوثيق:** يضيف `docs/README.md` و`docs/README.ar.md` مسارات منفصلة
   للمستخدم والمشرف والمطوّر، ويربط كل مسار بالمستندات الحية فقط.
3. **تشغيل المنتج:** توثيق متوافق للتثبيت عبر Docker، الإعداد، الأسرار، النسخ
   الاحتياطي والاستعادة، المراقبة، الدعم، وإجراءات الإصدار.
4. **استخدام المنتج:** تُوسّع أدلة المساعدة المضمّنة لتغطي البحث، السجلات،
   الرفع، الملفات، الحقوق، المشاركة، العمل الجماعي، والقوائم الإدارية، مع ربطها
   بواجهة `/help` بدل تكرار مواصفات API فيها.
5. **التطوير والتكامل:** تشرح وثائق المعمارية وLaravel وواجهة API المسار
   القانوني `archive-next/` + `archive-laravel/`، عقد OpenAPI، أوامر التحقق،
   وقواعد توافق العميل والخادم.
6. **الإصدار والحالة:** تفصل بوضوح بين الميزات المتاحة والميزات المشروطة أو
   غير المتحققة في بيئات حية، وتتطابق مع ملاحظات الإصدار وسجل الدعم.

## مصدر الحقائق وآلية التحديث

كل حقيقة تشغيلية أو تقنية تستند إلى مصدر قابل للتحقق داخل المستودع:

| الموضوع | المصدر المرجعي |
| --- | --- |
| أوامر المشروع والإصدارات | `package.json` و`infra/platform/toolchain.v1.json` |
| مسار المنتج والخدمات | `README.md` و`CLAUDE.md` وملفات Compose |
| واجهة API | `docs/api/archive-contract.openapi.json` |
| إعدادات البيئة | `infra/.env.example` وملفات Compose |
| ميزات الواجهة | مسارات `archive-next/` واختبارات التكامل |
| حالة الإصدار والدعم | ملاحظات الإصدار و`docs/versioning.md` |

لا تنشأ قائمة ميزات مستقلة ما لم تكن مرتبطة بالمصدر أو بعقد API. عند تغيير عقد
عام، يحدّث العقد وتطبيق Laravel وعميل Next.js والتوثيق باللغتين في التغيير نفسه.

## ضمانات الجودة

- فحص جميع روابط Markdown النسبية في نطاق التوثيق الحي، بما في ذلك روابط تبديل
  اللغة وفهرس التوثيق.
- مطابقة أوامر التثبيت والتحقق مع `package.json` قبل النشر.
- مراجعة عيّنة من كل دليل مقابل المسارات الفعلية وعقد OpenAPI، مع توثيق أي قدرة
  مشروطة صراحةً.
- تدقيق العربية للتأكد من سلامة اللغة والاتجاه والمصطلحات، ومراجعة الإنجليزية
  للوضوح وعدم نسخ قوالب Laravel الافتراضية غير المرتبطة بالمنتج.
- إجراء فحوص Markdown والروابط فقط؛ لا يتطلب تحديث النصوص تشغيل الخدمات أو
  تعديل الواجهات وواجهات API.

## إدارة الأخطاء والتباين

عند اكتشاف أمر أو ميزة أو حالة إصدار لا يمكن إثباتها من المصدر، لا تُذكر على أنها
حقيقة في الدليل. تسجّل كمعلومة تحتاج قرارًا أو تُصاغ كقدرة مشروطة مع رابط إلى
سجل الإصدار أو التحقق المناسب. أي اختلاف بين العربية والإنجليزية يعالج بتحديث
الصفحتين في الالتزام نفسه.

## اختبار القبول

يعد العمل مكتملًا عندما تكون كل وثيقة حية ضمن النطاق مصنفة في فهرس اللغتين، وكل
منها يملك نسخة عربية أو إنجليزية مكافئة وروابط تنقل سليمة؛ وتعكس حقائقها أوامر
المشروع والعقد والمسارات الفعلية؛ وتبقى الوثائق التاريخية منفصلة وموسومة بوضوح
كسجل غير حي.
