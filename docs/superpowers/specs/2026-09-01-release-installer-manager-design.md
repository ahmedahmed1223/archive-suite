# Release Installer Manager Design

## الهدف

إصدار أداة مستقلة مع `v1.5.2` تساعد المستخدم على اختيار طريقة تشغيل Archive Suite، وتنفذ الإعداد الأولي وتدير التثبيت بعده.

## الأصول المنشورة

ينشر سير الإصدار أصلين:

- `Archive-Suite-Installer-Windows.zip`، ويحتوي مشغل PowerShell وملف Batch سهل التشغيل.
- `archive-suite-installer-linux.tar.gz`، ويحتوي مشغل Bash.

الأداة خفيفة ولا تحمل صور Docker أو حزم Native بداخلها. تتصل بصفحة إصدار GitHub عند توفر الشبكة، أو تعمل من مجلد محلي يضم أصول الإصدار عند اختيار الوضع غير المتصل.

## واجهة الأداة

تعرض الأداة معالجاً تفاعلياً، مع أوامر غير تفاعلية قابلة للبرمجة:

```
archive-suite-installer doctor
archive-suite-installer install
archive-suite-installer status
archive-suite-installer start|stop|restart|logs|health|repair|backup
```

قبل التثبيت، تعرض نتيجة الفحص وخياراً مقترحاً ولا تنفذ تعديلاً قبل تأكيد المستخدم. خيارات التثبيت هي `docker` و`native` و`offline`.

## فحص البيئة

ينتج الفحص تقريراً منظماً يشمل نظام التشغيل وبنيته، توفر Docker Compose، وجود Docker daemon، المساحة المتاحة، الذاكرة، المنافذ المطلوبة، صلاحيات الكتابة في مسار التثبيت، وتوفر أدوات Native اللازمة.

يقترح `docker` إذا اجتاز Docker الفحص، وإلا يقترح `native` المطابق لنظام التشغيل. عند العثور على أجزاء Offline وملف التحقق في المجلد الحالي، يظهر خيار `offline` أولاً. يمنع المعالج الاستمرار عند فشل متطلب إلزامي ويعرض علاجاً مباشراً.

## التثبيت والإعداد الأولي

ينشئ المعالج مجلد تثبيت يختاره المستخدم، ومسار تخزين، وملف إعدادات محلياً بأذونات مقيدة. يطلب اسم المدير وكلمة مرور صالحة، وينشئ الأسرار اللازمة دون عرضها في السجل.

في Docker يستدعي Control Center الحالي بعد تحضير الإعدادات وواصف الإصدار. في Native يستخرج الحزمة المناسبة ويستدعي أدوات الإدارة المضمنة. في Offline يدمج الأجزاء، يتحقق من SHA-256، ثم يمرر الحزمة المتحققة إلى مسار Docker أو Native المناسب.

## الإدارة بعد التثبيت

يخزن ملف حالة غير سري في مجلد التثبيت يحدد نوع النشر والمسار ونسخة الإصدار. تعتمد أوامر الإدارة على هذا الملف للوصول إلى Control Center أو أدوات Native، وتعيد تقرير حالة موحداً. لا يحذف أي بيانات أو خدمة من دون تأكيد صريح.

## الأمان والصلاحيات

لا تقبل الأداة مسارات خارج مجلد العمل أو التثبيت عند استخراج الأصول. تتحقق من أسماء الأصول وتجزئتها وSHA-256 قبل التنفيذ. لا تسجل كلمات المرور أو الأسرار أو عناوين تحتوي بيانات اعتماد. تطلب التشغيل بصلاحيات مرتفعة فقط عند حاجة Docker أو خدمات Native إلى ذلك.

## الاختبار والإصدار

تختبر منطق اختيار الوضع، كشف الأصول، فحص المتطلبات، إنشاء خطة الإعداد، وصحة بيانات أصل الإصدار بوحدات Node. يختبر سير الإصدار إنشاء أرشيفي Windows وLinux، ثم يرفعهما مع الحزم Native وOffline وملفات التحقق.
