## المهمة التالية بالترتيب

1. شغّل `pnpm verify` من جذر المستودع. إن فشل، شخّص السبب بأصغر اختبار يعيد المشكلة، ولا تعالج فشلًا غير متعلق بهذه الشريحة داخل نفس الالتزام.
2. راجع صفحات الإصدار 2 مقابل احتياجات أرشفة الفيديو الواقعية: الاستيعاب، سجل المادة، التوصيف، المشتقات، الفحص، البحث، المهام، الصلاحيات، والاحتفاظ. وثّق الفجوات كمهام مستقلة قبل إضافة سلوك جديد.
3. لكل تعديل لعقد عام، حدّث وثيقة OpenAPI وتنفيذ Laravel وعميل Next.js وفحوص العقد في الالتزام نفسه.
4. اختبر الواجهة ببيانات تجريبية عبر المسار الموثق أو بالاختبار الحي؛ لا تنشئ حسابات أو بيانات إنتاجية لمجرد فحص بصري.
5. قبل اقتراح نشر، نفّذ بوابة التحقق الكاملة، راجع التغييرات غير التابعة للمهمة، ثم اطلب موافقة صريحة مستقلة للنشر.

## ملاحظات التنفيذ المهمة

- صفحة `/archive` تستخدم `api.search`، لا `api.records`. لذلك يجب أن يبقى `SearchController` محافظًا على `mediaSummary` بعد تحديد الصفحة، في البحث النصي والدلالي معًا.
