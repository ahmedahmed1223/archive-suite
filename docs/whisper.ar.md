# التفريغ باستخدام Whisper

[English](whisper.md) · [فهرس التوثيق](README.ar.md)

يستخدم Archive Suite البرنامج `whisper-ctranslate2` لتفريغ الوسائط. يستدعي
عامل Laravel البرنامج وينتج ملفات VTT وSRT وTTML، وتبقى هذه الملفات خاضعة
لصلاحيات السجل ومسار المراجعة نفسه.

## خط الأساس على CPU

يمثل التشغيل بالقيمتين `WHISPER_DEVICE=cpu` و`WHISPER_COMPUTE_TYPE=int8` خط
الأساس المتاح على أوسع نطاق. النموذج الافتراضي هو `large-v3`؛ خصص مساحة كافية
لذاكرة النماذج ووقتًا إضافيًا للحصول على النموذج في أول تشغيل. يمكنك اختيار
نموذج متوافق أصغر للاختبار أو للأجهزة محدودة الموارد قبل معالجة المواد الفعلية.

```dotenv
WHISPER_BINARY=whisper-ctranslate2
WHISPER_MODEL=large-v3
WHISPER_LANGUAGE=ar
WHISPER_DEVICE=cpu
WHISPER_COMPUTE_TYPE=int8
WHISPER_DIARIZE=false
```

## التشغيل على GPU

يوفّر عامل مستقل باسم `laravel-worker-gpu` تشغيل CUDA. وهو يحتاج إلى برنامج
تشغيل NVIDIA متوافق وNVIDIA Container Toolkit وذاكرة كافية للنموذج المختار.
شغّل ملف Compose الاختياري على جهاز GPU فقط:

```bash
docker compose -f infra/docker-compose.laravel-next.yml --profile gpu up -d laravel-worker-gpu
```

يستهلك هذا العامل طابور `gpu` فقط. عند اختيار `cuda` من إعدادات النظام، تُرسل
مهام التفريغ الجديدة إلى هذا الطابور وتستخدم `float16` دائمًا. يبقى عامل CPU
الافتراضي على طابور `default` مع `int8`. إذا اختير CUDA من دون عامل GPU سليم،
تفشل المهمة برسالة تشغيلية واضحة ولا تتحول بصمت إلى CPU.

## فصل المتحدثين والسلامة

فصل المتحدثين قدرة مستقلة عن التفريغ الأساسي. لا تفعّلها قبل إعداد رمز Hugging
Face المطلوب ومراجعة شروط معالجة البيانات لدى المزوّد. لا تضع `HF_TOKEN` في
المستودع أو السجلات أو حزم الدعم أو أصول الإصدار.

ناتج التفريغ محتوى مولّد آليًا. راجع الأسماء والتواريخ والعبارات الحساسة مقابل
المادة الأصلية قبل النشر. عند فشل المهمة، افحص تشخيص العامل وتأكد من إمكانية
الوصول إلى البرنامج وذاكرة النموذج، ثم أعد المحاولة من مسار مهام الوسائط.
