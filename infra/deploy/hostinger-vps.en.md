# Deploy Masar on a Hostinger VPS

[العربية](hostinger-vps.md) · [Documentation](../../docs/README.md)

Use this Docker guide on a supported Linux VPS. Install Docker Engine, Compose
v2, Node.js, and pnpm; clone the repository, run `pnpm install --frozen-lockfile`,
then start `pnpm setup`. Configure DNS before enabling public access and manage
health, backups, and updates through Control Center.
