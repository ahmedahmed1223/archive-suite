# مرجع خدمات البيانات في Kubernetes

[English](README.md) · [فهرس التوثيق](../../docs/README.ar.md)

يوفر هذا المجلد مراجع لخدمات البيانات في Kubernetes. يستخدم مسار التطبيق
المعتمد Docker أو Native على Windows وLinux. قبل تطبيق الموارد، استبدل كل
`CHANGE_ME` بقيمة سرية محمية وتحقق من حالة PostgreSQL وRedis بعد النشر.
